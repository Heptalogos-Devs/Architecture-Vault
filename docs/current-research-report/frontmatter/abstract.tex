\chapter*{摘要}
\addcontentsline{toc}{chapter}{摘要}

Nous Wave 围绕跨模型、会话和运行进程的长期主体认知开展研究。本报告整理主体身份、记忆、认知权威数据、运行时、离线认知、检索与外部资源的当前目标语义，并对照 Nous Wave 和 Heptalogos 代码基线说明实现状态。研究将来源证据、认知修订与检索视图分别建模，区分认知权限与行为权限，并给出持久化、并发控制、检索融合和投影重建的目标合同。

当前代码已包含基于 PostgreSQL 的认知权威数据、记忆服务、运行时和混合检索。自我、关系、动机、离线梦境流程、跨系统集成、检索排序稳定性及稠密检索后端选型仍处于待实现或待评测状态。研究资料包记录 EPA、Residual、Wave 和排序融合的局部试验摘要；后续工作将补充原始试验材料，并按目标语料评估算法效用。

\textbf{关键词：} 长期主体；认知系统；记忆语义；证据溯源；认知运行时；关联检索
