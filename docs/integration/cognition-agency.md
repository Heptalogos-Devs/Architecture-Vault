# Nous Wave 与 Heptalogos：认知与主动性

## 共同主体

Nous Wave 与 Heptalogos 服务同一个逻辑 Subject，并共享稳定 `SubjectId`。

Nous Wave 维护长期认知：记忆、自我、社会认知、动机、认知运行时以及这些认知的来源和修订。

Heptalogos 维护行为与产品运行：交互输入、主动性、行为决定、承诺、外部效果、系统管理和运行可靠性。

## 认知输入的 Authority

Nous Wave 的持久 cognition 表示 Subject 当前或历史认知及演化，不认证命题客观为真。Heptalogos 接收 cognition 时保留 exact object/revision identity、provenance、实际 formation basis、适用范围和可修订的 epistemic judgment；来源真实、形成时使用过与语义上支持某命题分别表达。

误解、矛盾、过时认知和后续 correction 都可以是合法认知输入。模型 producer identity 和 grounded formation 不赋予事实证明或行为权限。Heptalogos 按自己的行为合同审查这些输入；Nous Wave 的 owner 继续负责 Subject 归属、身份、权限、生命周期、幂等、清除和历史视图等结构保证。新 cognition 不改写此前历史。

## 期望条件

Nous Wave 的 Motivation 可以形成期望条件。期望条件描述主体希望某个状态在指定时间语义下成立或保持不成立。

期望条件有自己的稳定身份和修订。它的存在只表示认知上的期望。

## 主动追求

Heptalogos 可以根据期望条件、当前情境、注意、行为政策、现有承诺、资源和外部机会形成主动追求。

主动追求引用期望条件的精确修订。采纳、暂停和结束主动追求属于 Heptalogos 的行为状态。

期望条件修订后，相关主动追求重新核验。期望被撤回后，Heptalogos 仍保留已经发生的 DecisionCommit、Commitment 和外部效果历史。

## 行为链

一次具体行为仍通过 Reaction 和行为权威链产生。主动追求可以生成新的认知处理机会，也可以影响一次行为提议；它不会直接形成外部效果。

## 结果回传

Heptalogos 将行为结果、承诺状态和可观察外部事实作为带来源的回执提供给 Nous Wave。Nous Wave 根据这些材料更新记忆、动机或其他认知。

行动完成和期望满足分别评价。一个行动计划完成后，期望条件仍可能未满足；一个期望条件满足后，也不要求抹除相关行为历史。

## 管理与安全

安全政策、管理员强制规则、行为许可和外部效果审查由 Heptalogos 维护。Cognitive Seed 和其他认知内容可以影响主体理解和行为倾向，但不能取得这些规范权限。
