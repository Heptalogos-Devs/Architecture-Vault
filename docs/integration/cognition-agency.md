# Nous Wave 与 Heptalogos：认知与主动性

## 共同主体

Nous Wave 与 Heptalogos 服务同一个逻辑 Subject，并共享稳定 `SubjectId`。

Nous Wave 维护长期认知：记忆、自我、社会认知、动机、认知运行时以及这些认知的来源和修订。

Heptalogos 维护行为与产品运行：交互输入、主动性、行为决定、承诺、外部效果、系统管理和运行可靠性。

## 正式认知集成与原生执行

软件依赖方向为 Heptalogos → Nous 官方 SDK/OpenClaw 集成 → Nous 公共服务。Nous 集成可独立安装和运行，不依赖 Heptalogos 包、数据库、旧 AIRuntime 或 Foundation；Heptalogos 装载相同产物，不另写 persona/memory/social/language 选择与接线。认知域与产品生活能力分别按完整功能交付。

Subject 可无 Seed，也可采用人类可读 soul 来源。它是独立个体，Host、模型、consumer 和执行者分别标识。未提供的经历或人格不被初始化过程补写；Seed 原文、adoption 与当前认知保有独立来源和修订。当前 soul 只是正式对象的派生视图，不与认知数据库双写。

实际模型提交前按当前工作、用途、参与者、受众与能力范围自动准备和应用 Projection/Managed Context，覆盖首轮、工具后续、重试、压缩和子 Agent。一个并行执行者使用独立 binding/cursor，但共享同 Subject 的唯一持久认知。身份/受众来自认证 Host 上下文，模型工具不能自行扩大范围。

RESET 真正替换当前 slice；原生压缩不吸收当前认知为永久摘要。必需模式缺失认知时停止相关调用，不能退回默认路径继续执行。原生接口覆盖不了该语义时，在受控 OpenClaw 分发修正唯一正式入口，不套 best-effort hook 冒充保证，也不另造通用 Agent Runtime。

OpenClaw 保有原生工具、渠道、Computer use、skills、子 Agent、模型连接和 transcript。Host 明确配置工具可见性、执行政策、目标凭据及 OS/节点范围；认知提示词不代替权限控制。未进入主体感知的后台来信不能通过通用 ingest 偷渡进认知。

## 认知输入的 Authority

Nous Wave 的持久 cognition 表示 Subject 当前或历史认知及演化，不认证命题客观为真。Heptalogos 接收 cognition 时保留 exact object/revision identity、provenance、实际 formation basis、适用范围和可修订的 epistemic judgment；来源真实、形成时使用过与语义上支持某命题分别表达。

误解、矛盾、过时认知和后续 correction 都可以是合法认知输入。模型 producer identity 和 grounded formation 不赋予事实证明或行为权限。Heptalogos 按自己的行为合同审查这些输入；Nous Wave 的 owner 继续负责 Subject 归属、身份、权限、生命周期、幂等、清除和历史视图等结构保证。新 cognition 不改写此前历史。

## 期望条件

Nous Wave 的 Motivation 可以形成期望条件。期望条件描述主体希望某个状态在指定时间语义下成立或保持不成立。

期望条件有自己的稳定身份和修订。它的存在只表示认知上的期望。

## 主动追求

Heptalogos 可以根据期望条件、当前情境、注意、行为政策、现有承诺、资源和外部机会形成主动追求。

主动追求引用期望条件的精确修订。采纳、暂停和结束主动追求属于 Heptalogos 的行为状态。

期望条件修订后，相关主动追求重新核验。期望被撤回后，Heptalogos 仍保留已经发生的 DecisionCommit、Commitment 和外部效果历史。

## 行为链

一次具体行为仍通过 Reaction 和行为权威链产生。主动追求可以生成新的认知处理机会，也可以影响一次行为提议；它不会直接形成外部效果。

模型可以同次形成行为候选与草稿；产品行为采纳在真实执行/外发之前成立，表达不得改变已采纳语义。message hook 超时或失败后继续发送的机制不能独自承担许可。最终出口检查当前行为、受众与敏感来源条件；缺少必需控制时修正正式入口。

## 结果回传

Heptalogos 将行为结果、承诺状态和可观察外部事实作为带来源的回执提供给 Nous Wave。Nous Wave 根据这些材料更新记忆、动机或其他认知。

行动完成和期望满足分别评价。一个行动计划完成后，期望条件仍可能未满足；一个期望条件满足后，也不要求抹除相关行为历史。

认知准备、实际输入应用、provider 传输、行为采纳和外部结果分别报告。模型输出不是已发送消息；工具/渠道成功、失败、取消和 uncertain 按已发生事实回流。普通 transcript 不自动成为 accepted Memory，模型引用也不证明其内部因果。

## 生活、时间与运行

Heptalogos 维护生活日程、已采纳活动、消息感知、注意、自然回应节点与打断。Subject 可以继续工作、等待、休息或延后来信；来信先由产品保存，真正接触时才形成 Nous Observation。虚拟环境按实际事件和结果形成经历，计划与已完成分开；显式世界时钟不加速基础设施超时。

无图形管理进程、API 和 CLI 可独立控制已交付功能。主体与机器运维 OpenClaw 是不同运行实例，凭据、权限、入口及生命周期隔离。系统维护实例不依赖主体认知或正常产品启动，普通主体渠道不能取得维护能力。

## 管理与安全

安全政策、管理员强制规则、行为许可和外部效果审查由 Heptalogos 维护。Cognitive Seed 和其他认知内容可以影响主体理解和行为倾向，但不能取得这些规范权限。

普通聊天中的“记住/忘记”、用户赞同或纠正是交谈和来源，不直接授权认知修改、purge 或系统管理。显式管理请求通过认证入口与 owning 操作处理。
