# Repository Governance Instructions

This scope defines durable repository roles and knowledge ownership.

- Document repository responsibilities and stable ownership boundaries only.
- Keep active transfer, rename, archive, and external-service migration status in an authorized task record, not in this maintained model.
- Do not decide the status of a legacy repository from age or an earlier provisional classification. Verify its purpose and dependencies before recording a durable decision.
- Update the root and documentation indexes when this scope's entry points change.
