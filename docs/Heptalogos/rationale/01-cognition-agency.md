# 认知与主动性

## 设计问题

持续主体需要区分“希望什么”与“已经决定追求什么”。期望可以在主体暂时不行动时继续存在；主动追求会占用行为注意和资源，并可能产生承诺与外部效果。若两类状态共用一个生命周期，认知状态就会携带行为权限。

Nous Wave 中的期望条件描述主体希望成立、停止、维持或避免的状态。Heptalogos 需要另外表示行为侧是否采纳该期望并持续投入主动性。

## 方案比较

**由认知系统维护一个统一 Goal 生命周期。** 这种方案让愿望、计划和执行进度共享一个入口，但会把行为采纳、资源投入、暂停和外部结果带入 Nous Wave，模糊认知与行为权威边界。

**只在 Nous Wave 保存期望条件。** 该方案避免认知系统维护行为状态，但无法由 Heptalogos 明确表示某个期望已经经过行为审查并获得持续资源投入；后续每次行为都要自行推断这一事实。

**分离期望条件与 Pursuit。** Nous Wave 维护期望条件，Heptalogos 维护已采纳的主动追求。该方案保留认知和行为各自的权威，并要求两个系统通过精确修订引用和结果回执协作。

## 当前选择

Heptalogos 使用 `Pursuit` 表示行为侧已经采纳并持续投入资源的主动追求。每个 Pursuit 引用 Nous Wave 期望条件的精确修订，并保存行为侧自己的状态和来源。

一次 Reaction 中的 `BehaviorIntent` 表示具体行为提议；`ActionPlan` 或 `InteractionPlan` 表示实现方式；`Commitment` 与 `Obligation` 表示已经承担的约束。它们分别维护身份和生命周期。

## 失败模式与设计后果

- 若期望条件自动创建 Pursuit，认知存在就会隐式获得行为权限。Heptalogos 必须独立审查是否采纳、延迟、暂停或结束 Pursuit。
- 若期望条件修订后 Pursuit 自动跟随，新旧语义会被静默合并。Heptalogos 必须重新核验精确修订；重新核验不改写既有 `DecisionCommit`、承诺或外部效果。
- 若一次行动失败被视为期望失败，局部执行结果会错误终结长期认知。行为结果应以有来源的证据和回执返回 Nous Wave，由认知系统评价期望是否满足。
- 若一次 `ActionPlan` 成功被视为期望满足，局部目标完成会冒充长期状态证据。两者必须分别评价。

## 已确定与未决事项

期望条件与 Pursuit 的权威归属、精确修订引用、重新核验义务，以及 Pursuit 与行为提议、计划和承诺的区别已经确定。Pursuit 的暂停、恢复、关闭原因、并发数量以及撤回后的既有承诺处理仍待 Heptalogos 继续设计，见[未决问题](../OPEN_QUESTIONS.md)。

## 术语

本设计不使用单一 `Goal` 同时表示愿望、期望条件、主动追求、计划和承诺。跨系统合同分别使用“期望条件”和“主动追求”。
