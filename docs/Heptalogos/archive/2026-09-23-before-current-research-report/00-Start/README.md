## AI Agent

先读 [AI Agent 指南](Agent-Guide.md)，然后按任务读取，不要默认扫描整个 Vault。

最小上下文通常是：

```text
Project Vision
+ System Overview
+ Current State
+ one relevant concept
+ one relevant engineering document
+ related decision, if any
```
