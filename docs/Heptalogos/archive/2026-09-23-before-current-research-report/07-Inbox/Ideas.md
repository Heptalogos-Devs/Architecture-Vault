# Ideas

按以下格式随手追加：

```markdown
## YYYY-MM-DD：标题

想法、动机、可能影响。
```

## 2026-08-03：可扩展叙事界面

长期对话和主体经历可能适合以时间线、节点和超文本方式呈现，而不只是聊天记录。可以研究让事件、人物、承诺、日记和自我叙事相互链接的阅读界面，但这属于 Control Plane / 产品体验研究，不应改变事实权威模型。

## 2026-08-03：模型任务路由

不同认知阶段可使用不同模型：规则或小模型做预筛，强推理模型做行为和规划，中型模型做表达，离线低成本模型做日记。路由应基于任务契约、实测能力、成本和隐私，而不是只匹配模型描述。

## 2026-08-03：语义能力折叠

工具过多时，不把全部 schema 注入模型。先根据任务和权限检索少量 Capability Descriptor，再展开具体 schema。需要防止能力检索本身变成越权入口。
