# Inbox

这里接收尚未整理的想法、讨论摘录、外部资料和问题。

## 使用方式

- 不需要 frontmatter；
- 不要求完整；
- 可以直接粘贴对话和链接；
- 标明日期和大致来源即可；
- 任何成员或 Agent 都可以整理到正式文档；
- 整理完成后删除或保留一行去向说明。

## 去向

- 项目目标与边界 → `01-Vision/`
- 系统结构与权威 → `02-System/`
- 人格、记忆、关系等概念 → `03-Concepts/`
- 当前实现与近期开发 → `04-Engineering/`
- 长期关键选择 → `05-Decisions/`
- 实验、论文和对比 → `06-Research/`
