\chapter{认知系统接入}

Nous Wave 是 Subject 的长期认知系统。它提供记忆、自我、社会认知、动机、认知运行时及其来源和修订。

Heptalogos 通过稳定的认知查询与上下文贡献合同读取这些状态。认知系统返回的内容保留认知来源、对象身份和修订信息。

认知内容能够影响行为判断、注意和主动性。对其他领域的写入通过提案或正式操作完成。

Heptalogos 不复制 Nous Wave 的内部认知对象。记忆、自我、社会认知、动机等内部数据模型由 Nous Wave 维护。

认知系统不可用时，Heptalogos 根据当前功能就绪条件决定降级或阻塞。产品宿主、管理和恢复能力继续保持独立。
