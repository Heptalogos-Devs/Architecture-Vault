\chapter{系统定义}

Heptalogos 是持续 Subject 的产品运行与行为系统。它承载真实即时通信环境中的交互、主动性、行为决定、承诺、外部效果、产品管理和运行可靠性。

Subject 的长期认知由 Nous Wave 维护。Heptalogos 使用这些认知形成上下文和行为判断，同时保留自己的行为权威。

模型、供应商、会话、平台和 Host 进程都可以替换。它们的变化不产生新的 Subject。

Heptalogos 的产品目标包括：在异步、多会话、多平台环境中保持 Subject 的行为连续性；在外部世界不确定时保存真实结果；使重要行为和状态变化能够追溯；让管理员和机器运维拥有清晰、独立的权限路径。
