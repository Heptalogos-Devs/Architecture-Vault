\chapter*{摘要}
\addcontentsline{toc}{chapter}{摘要}

Nous Wave 是面向长期运行人工智能主体的可组合认知与人格平台。主体身份独立于模型、会话、进程和检索索引；持久认知、认知运行时与检索服务投影分别维护。系统以可追溯的观察与证据为基础，管理记忆、自我、社会认知、动机及其修订，并通过认知查询、运行时工作集和离线认知流程向宿主提供持续的主体状态。

记忆型能力组合可以独立服务普通智能体和检索增强生成系统；完整主体能力组合在同一认知基础上增加自我、社会认知、动机与跨领域离线认知。Nous Wave 与 Heptalogos 共享稳定主体标识，但分别维护认知权威与行为、规范及外部效果状态。模型服务、外部知识资源和检索算法均属于可替换机制，不决定主体身份或认知真值。

\textbf{关键词：} 长期主体；认知系统；记忆；自我；社会认知；动机；认知运行时；证据溯源；检索
