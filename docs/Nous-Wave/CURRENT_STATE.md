## 与目标设计尚未对齐的主要部分

- `MemoryClass = Specific | Integrative | Procedural` 仍是互斥分类；目标设计要求认知角色与形成方式分别表示。
- `Anchor` 仍是权威对象；目标设计使用认知图式与可重建联想拓扑分别承担认知和检索职责。
- `AssociationEvidence.support_value` 仍承担过多通用权重语义。
- 排序仍包含依赖当前候选集合的归一化和额外拓扑奖励。
- 查询计划还没有完整冻结每个检索通道的预算、权重和融合合同。
- 使用回执缺少调用方提供的稳定长期事件标识，重试可能重复记账。
- 自动可访问性仍采用 90/365 天硬分档；目标设计只固定查询时动态可访问性语义。
- 认知图式、自我、社会认知、动机以及完整离线认知尚未形成可执行的权威合同。
- 加权主成分分析仍有样本重复次数与协方差不一致的问题；当前竞争式传播的状态合并仍属于实验性近似。
