\chapter{不变量与主要数据流}

\section{权威数据不变量}

\begin{itemize}
\item 主体（Subject）$\neq$ 模型（Model）；认知权威 $\neq$ 行为权威。
\item 原始材料（Artifact）$\neq$ 观察事件（ObservationOccurrence）$\neq$ 记忆（Memory）。
\item 消息事实（MessageFact）$\neq$ 记忆；资源检索结果 $\neq$ 已接受认知。
\item 检索命中 $\neq$ 服务投影 $\neq$ 实际使用 $\neq$ 认知强化。
\item 材料提及（Mention）$\neq$ 认知指向（Aboutness）；证据谱系 $\neq$ 独立佐证数量。
\item 假设（Hypothesis）$\neq$ 已接受认知；主体目标（Goal）$\neq$ 行为承诺（Commitment）。
\item 检索服务投影 $\neq$ 认知权威。
\item 工作集淘汰 $\neq$ 忘却；忘却 $\neq$ 抑制 $\neq$ 清除。
\end{itemize}

\section{认知形成与检索主链}

\begin{enumerate}
\item 主体实际接触原始材料或事件，形成观察事件（ObservationOccurrence）。
\item 证据引用（EvidenceRef）固定来源区域、派生表示和来源谱系。
\item 认知提案绑定主张、语义指向、当前修订和证据。
\item 语义领域所有者核验来源、访问控制及对象版本后，提交不可变修订。
\item 权威数据变更触发相应投影类别的更新。
\item 查询计划在检索前固定通道与预算，多个视图按对象和修订聚合。
\item 返回前重新核验当前修订、生命周期、访问控制和材料展开状态。
\end{enumerate}

\section{离线维护主链}

宿主或 Heptalogos 提供维护租约与预算；Nous 固定来源快照后执行有界回放、关联扩展和反例搜索；结果先形成假设；随后重新核验来源与当前版本；最后由记忆、自我、关系或动机领域所有者决定接受、拒绝、标记冲突或过期。
