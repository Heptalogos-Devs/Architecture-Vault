\chapter{不变量与主要数据流}

\section{权威数据不变量}

\begin{itemize}
\item Subject $\neq$ Model；Cognitive Authority $\neq$ Heptalogos Behavior/Normative Authority。
\item Artifact $\neq$ ObservationOccurrence $\neq$ Cognition；MessageFact $\neq$ Memory。
\item Source Mention $\neq$ Cognition Aboutness；evidence lineage $\neq$ independent support count。
\item Memory cognitive role $\neq$ formation mode；Relationship degree $\neq$ epistemic certainty。
\item Hypothesis/proposal $\neq$ accepted cognition；Goal $\neq$ Commitment。
\item retrieved/ranked $\neq$ exposed $\neq$ referenced/acted-on $\neq$ reinforced。
\item UseEvent retry $\neq$ new use；durable use/outcome feedback 以稳定 event identity 幂等提交。
\item Relationship Authority Graph $\neq$ Associative/Serving Topology。
\item Resource awareness $\neq$ Resource contents $\neq$ Subject cognition。
\item Durability $\neq$ Accessibility $\neq$ Relevance；Accessibility $\neq$ Truth $\neq$ Suppression $\neq$ Purge。
\item 自然语言“忘掉” $\neq$ destructive management authority。
\end{itemize}

\section{认知形成与检索主链}

\begin{enumerate}
\item Subject 实际接触材料或事件，记录 ObservationOccurrence 与稳定来源。
\item EvidenceRef 固定 source/derived representation 与 provenance root。
\item Formation/Revision proposal 绑定 target owner/object、claim/content、aboutness、expected revision/epoch 和 evidence。
\item Memory/Self/Social/Motivation owner 核验来源、权限、对象版本和 owner-specific semantics 后提交 immutable revision 或 typed relation。
\item Authority change 以同一可靠提交顺序推进 subject/owner sequence，并触发对应 Serving generation invalidation/outbox。
\item QueryPlan 在候选前冻结 lanes、budgets、hard filters 与 fusion weights；各 lane 先按 object/revision 聚合多 views。
\item fixed-plan fusion / optional rerank 后，在返回或 materialization 前重新核验当前 revision、lifecycle、access/ACL 与 purge/suppression 状态。
\item 调用方真正消费 cognition 后，以 caller-stable UseEvent/Outcome receipt 幂等回报；candidate/retrieval trace 不自动形成 reinforcement。
\end{enumerate}

\section{Memory Reference Profile 主链}

\begin{center}
Observation $\rightarrow$ Evidence/Provenance $\rightarrow$ Memory Formation/Revision\\
$\rightarrow$ PostgreSQL Authority $\rightarrow$ Exact/Entity/Lexical/Dense Serving\\
$\rightarrow$ fixed QueryPlan + object-level fusion $\rightarrow$ Use/Outcome Receipt\\
$\rightarrow$ Accessibility/Runtime update $\rightarrow$ Suppress/Restore/Purge/Recovery
\end{center}

该主链是 2026-10-27 前优先形成完整资格证据的纵向实现。Episode、Journal、CognitiveSchema、Social、Self、Motivation、Dream 保持目标设计，但不作为该闭环的 correctness 前置。

\section{离线维护主链}

Heptalogos 或其他 Host 提供 maintenance opportunity/lease 与预算；Nous 固定输入 revision/source snapshot 后执行有界 replay、association/schema exploration、counterevidence search；结果先形成 Hypothesis；随后重新核验当前 evidence/owner state；最后由 Memory、Self、Social 或 Motivation owner 决定接受、拒绝、修订、标记冲突或保持未决。维护窗口不赋予 Dream 绕过 owner authority 的权限。
