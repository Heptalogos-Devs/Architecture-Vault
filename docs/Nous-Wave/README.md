# Nous Wave 文档

本目录保存 Nous Wave 的长期目标设计、已接受设计决定、设计论证、研究证据和未决设计问题。当前实现、实现审查、实施计划、可执行规格和资格记录由 [Nous-Wave 代码仓库](https://github.com/Heptalogos-Devs/Nous-Wave)维护。

## 入口

- [目标设计正文](TARGET_DESIGN.md)：唯一直接编辑的 Nous Wave Target Design Authority。
- [设计决定](DECISIONS.md)：已接受结论及其论证入口。
- [未决问题](OPEN_QUESTIONS.md)：仍需研究、实验或后续 Spec 决定的事项。
- [设计论证](rationale/README.md)：方案比较、取舍和失败模式。
- [研究与证据](research/README.md)：外部资料、算法试验和本轮研究综合。
- [Vault 文档职责](../DOCUMENT_MODEL.md)：文档所有权和权威顺序。

Target Design 只描述长期目标语义、领域边界、对象关系和系统约束。代码状态、实现差距、施工顺序和资格证据不进入本目录。

## 发布物

本目录当前没有活动的 LaTeX authoring source 或自动 PDF 构建流程。未来阶段性发布如需 PDF，应从 TARGET_DESIGN.md 建立并验证确定性的派生流程后单独执行；发布物不形成并行 Authority。
