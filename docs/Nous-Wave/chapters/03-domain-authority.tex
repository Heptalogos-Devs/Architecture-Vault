\section{权威类型}

当前目标将下列权威分别交由相应领域维护：

\begin{description}
\item[来源权威] 记录来源实际表达或发生的内容。
\item[认知权威] 由记忆、自我、关系或动机领域接受认知修订。
\item[规范与行为权威] 由 Heptalogos 管理允许、禁止和承诺的行为状态。
\item[管理权威] 决定抑制、清除、配置或主体管理操作的权限。
\item[主体构成约束] 区分主体初始认知中的可演化部分与系统、产品约束；细节仍待定。
\end{description}

操作者身份与语义权限分别判定；写入权限由管理身份和目标领域合同共同决定。模型输出、离线假设、用户请求和管理员操作均按各自权限处理。跨域写入以类型明确的提案表达，包含目标领域、预期状态、输入修订、证据和生产者来源；目标领域所有者重新验证后，决定提交、拒绝或标记冲突。

\section{主体标识与分支}

主体标识（SubjectId）由宿主或客户端提供。实现分支复制（fork）时分配新的 SubjectId，分支共享继承点以前的不可变修订谱系，之后分别维护可变头指针、对象纪元和抑制/清除状态。\cite{nous-research-package,olson2023}

个人身份研究中的心理连续性、数值身份与分支提供不同分析视角；软件分支的 SubjectId 规则由工程合同确定。
