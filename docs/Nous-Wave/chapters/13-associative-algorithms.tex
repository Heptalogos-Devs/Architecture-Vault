\section{Wave 与 PPR}

Wave 用于预算受限的竞争式联想扩展。当前实现会合并相邻节点状态；若路径预算或动量影响后续合法可达性，仅按前一状态和当前状态合并就可能借用或丢失路径预算。研究资料包因此把 Wave 保留为待比较方案，并要求与保留充分状态的实现、类型化 PPR/扩散、非回溯扩展和无拓扑基线在相同预算下对比。\cite{nous-research-package,nous-code-snapshot}

目标研究建议以类型化、有界 PPR/扩散作为可解释基线。参数、边类型、种子构造和截断策略仍需实验决定；比较结果属于检索证据，认知真值由权威数据维护。

\section{残差金字塔}

研究资料包报告：在精确余弦服务方和相同 MGS 条件下，1000 组随机输入的路径、能量和最终残差保持一致。该结果反映此实验设置下的核心数学转写一致性；真实语料检索效用和用户任务表现列入后续评测。源代码通过有界候选搜索、正交基构造和残差能量停止条件实现该方法。\cite{nous-research-package,nous-code-snapshot}

\section{EPA 加权问题}

当代表向量的重复次数不同，加权均值和协方差都应保留样本密度。研究资料包报告，只对均值加权、却未以 $\sqrt{weight}$ 缩放矩阵行，会改变主方向；构造反例的偏差约为 $21.2^\circ$，并称 1000 组随机实验中偏差经常显著。该结果指出需先保持数学处理一致，再评估 EPA 对检索的贡献。\cite{nous-research-package}

当前 \SourcePath{crates/memory-retrieval/src/cue_sensing.rs} 在均值计算中使用代表向量权重，构造中心化 SVD 矩阵时尚未按代表次数缩放各行；对应修正列入实现待办。\cite{nous-code-snapshot}

\section{排序稳定性}

研究资料包报告的反例显示：添加一个低分且带有新证据类别的无关候选后，按当前候选集合归一化可能改变原候选 A/B 的相对顺序。当前 \SourcePath{crates/memory-retrieval/src/ranking.rs} 仍据候选中出现的类别动态计算启用集合；固定查询计划中的证据类别和权重列入实现待办。\cite{nous-research-package,nous-code-snapshot}
