\chapter{待解决的研究问题}

\section{语义类型与领域所有权}

\begin{enumerate}
\item \textbf{自我构成：} 认知种子中哪些内容参与自我修订演化，哪些由宿主或系统宪制约束？涉及构成约束的认知，应由何种管理操作允许覆盖或重释？
\item \textbf{动机范围与生命周期：} 价值观、需要和兴趣如何归属？目标冲突、激活、满足、放弃和暂停分别需要哪些最小语义？
\item \textbf{认知图式归属：} 图式可否由综合型记忆完整表达，还是需要独立身份、生命周期、查询和写入合同？
\end{enumerate}

\section{治理规则与可靠性合同}

项目组需明确来源依赖变化、访问权撤销、过期提案、证据独立性、清除后的审计元数据、主体分支谱系清理，以及跨领域提案的当前状态核验。每项规则均需落实到责任领域和失败合同。

\section{算法与评测}

后续对照试验包括：

\begin{itemize}
\item 在相同图和预算下比较无拓扑、单跳、类型化 PPR、非回溯扩展和保留路径状态的 Wave；
\item 修正 EPA 权重处理后测量弱线索检索效用；
\item 比较 Residual、稠密检索、结构化多查询和模型分解；
\item 评估对象级多视图聚合与固定查询计划的排序稳定性；
\item 对照无衰减、仅按时间衰减、时间与类型化使用联合调整等可访问性方案；
\item 比较梦境探索和常规记忆整理在支持精度、反例召回、重复循环与计算成本方面的表现。
\end{itemize}

\section{部署与模型服务}

本机部署需通过真实过滤、多视图查询、重建、崩溃恢复和备份恢复评测，在 Qdrant 与 pgvector 之间确定稠密检索方案，并明确安装、更新、备份、恢复、模型服务和外部资源适配流程。

\section{实现合同}

记忆角色集合、经历片段边界信号、活动状态阈值、关系字段、梦境探索种子与停止策略，以及 SQL、Proto、Rust、TypeScript 接口，需通过规格或实验收敛。主体分支写时复制和本地模型配置也需纳入实现合同。\cite{nous-research-package}

\section{与 Heptalogos 的集成}

Heptalogos 是完整主体档案的主要目标使用方。跨库集成需先确定 SubjectId 提供方式、认知提案、使用与结果回执、维护租约，再以端到端场景确认两侧的权威数据和失败处理。
