# 算法研究证据

本文件记录已经完成的局部性质验证。所有数值只支持相应实验条件下的结论，不自动决定生产默认算法。

## 加权主成分分析：样本重复次数

### 问题

压缩表示使用一个代表向量表示多个重复样本时，如果只在均值中使用样本数，却没有在协方差和奇异值分解中保留样本数，主方向是否会改变？

### 数学结构

给定代表向量 \(x_i\) 和它代表的样本数 \(w_i\)，加权均值为：

\[
\mu=\frac{\sum_i w_i x_i}{\sum_i w_i}
\]

为了保留重复样本对协方差的贡献，中心化矩阵第 \(i\) 行应为：

\[
y_i=\sqrt{w_i}(x_i-\mu)
\]

随后对由这些行组成的矩阵进行奇异值分解或主成分分析。

### 已记录结果

构造反例使用三个代表向量，样本数分别为 `240 / 40 / 20`。仅对均值加权与完整保留样本密度的计算相比：

- 第一主方向夹角约为 **21.217°**；
- 第一主轴能量比例约为 **0.6652 与 0.7510**。

随机实验中也频繁出现明显主方向差异。

### 结论边界

这些结果说明：如果压缩实现只计算加权均值，却不按 \(\sqrt{w_i}\) 缩放中心化矩阵行，就没有保持原始重复样本对应的协方差几何。

这些结果**不能**证明该算法一定降低最终检索质量。正确顺序是先修正数学语义，再在固定语料与查询集上比较实际检索收益。

## 残差语义线索：核心数学差分

### 问题

在相同精确余弦候选提供器和修正 Gram-Schmidt 正交化条件下，Nous Wave 的残差计算与参照实现是否存在候选路径、能量或最终残差差异？

### 已记录结果

**1000 组随机试验**中未发现：

- 候选路径不一致；
- 能量不一致；
- 最终残差不一致。

### 结论边界

这些结果支持受控条件下“残差 → 正交子空间 → 投影与扣除”核心数学转写的一致性。

它们不能证明这种方法对真实语料的召回率、精确率、延迟或成本有正收益。真实检索效用仍需独立评测。

## 竞争式传播：状态合并

### 问题

如果剩余路径预算或动量会影响未来合法转移，把不同历史状态合并到同一个“前一节点、当前节点”状态后，是否还能保持正确的未来可达性？

### 已记录结果

研究记录中的 **20,000 组性质试验**显示：

- Nous Wave 当前路径预算合并的违规频率约 **55.735%**；
- 相应平均绝对误差约 **0.34886**；
- 参照实现的动量合并也出现相近频率的状态近似，平均绝对误差约 **0.10443**。

这些数值描述构造性质测试，不代表线上查询质量。

### 结论边界

当路径预算或动量影响未来转移时，简单合并能量、同时只保留某一路径状态，不是一般意义上的等价变换。

后续至少需要在相同图、种子、硬过滤和计算预算下比较：

- 无拓扑扩展；
- 有界类型化 PageRank/扩散；
- 保留充分状态的竞争式传播；
- 必要时加入非回溯或单跳等更简单图基线。

## 排序融合：候选集合依赖

### 问题

如果融合分母由本批候选实际出现的证据类别动态决定，加入一个与原有 A、B 无关、但带有新证据类别的候选 C，会不会改变 A、B 的相对顺序？

### 已记录结果

随机 **20,000 对**比较中出现 **710 次**原候选相对顺序翻转，约 **3.55%**。

### 结论边界

依赖当前候选集合的归一化不能保证“加入无关候选后，原有候选相对尺度保持稳定”。

目标查询计划因此要求在候选产生前固定检索通道、权重和融合参数。具体参考融合公式与替代方案见 `../rationale/05-retrieval-fusion.md`。
