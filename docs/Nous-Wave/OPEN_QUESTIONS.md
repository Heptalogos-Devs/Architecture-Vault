# Nous Wave 未决问题

本文件只记录尚未进入目标设计或尚未下降为可执行规格的事项。已经明确的领域边界不在这里重复讨论。

## 宏观设计问题

### 自我与认知种子的构成性语义

已经确定：认知种子用于初始化自我；系统宪制属于宿主或 Heptalogos 的规范权威；人格风格属于自我领域；普通认知修订不能覆盖系统宪制。

仍需决定：

- 认知种子中是否需要“构成性但仍属于认知”的特殊状态；
- 如果存在，这类状态与普通自我修订的区别；
- 主体自身能否重新解释或逐步修改这类状态；
- 管理员强制修改与主体自然演化如何分别留痕；
- 身份、价值、倾向和叙事发生冲突时如何收敛。

### 动机的完整生命周期

已经确定：愿望、目标、关切和优先关系属于 Nous Wave 的认知；承诺、义务、计划和外部行动属于 Heptalogos。

仍需决定：

- 需要与兴趣应进入动机领域，还是由自我或记忆表达；
- 目标满足、放弃、暂停、恢复和冲突的正式状态；
- 多目标冲突的长期表示；
- 哪些优先关系持久化，哪些只在认知运行时计算；
- 何时把一次临时意图提升为长期目标；
- Heptalogos 对目标的拒绝、完成和取消如何反馈到目标生命周期。

## 规格层问题

- 社会关系类型的最小规范集合；
- 哪些关系类型允许程度属性，以及程度使用有序等级还是具有明确量纲的连续测量；
- 语言惯例的作用域编码和形成接受阈值；
- 经历片段边界信号的具体组合；
- 活动认知的容量、降级与恢复策略；
- 离线认知的种子选择、停止规则与反例搜索细节；
- 自动可访问性的默认函数和参数；
- 稠密检索后端的最终选型；
- 多视图聚合的默认上限与规则。

## 算法研究问题

- 联想拓扑在目标工作负载上是否相对无图检索提供足够增量收益；
- 个性化 PageRank、保留充分状态的竞争式传播或更简单图扩展的质量—成本比较；
- 残差语义线索是否提高弱线索召回；
- 修正加权协方差后，主成分方法是否仍有独立价值；
- 固定计划的倒数排序融合是否需要被经过校准或学习得到的融合方法替代。
