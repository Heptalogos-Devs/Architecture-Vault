# 记忆分类与认知图式

## 已确定的设计

记忆使用两个彼此独立的属性描述：**认知角色**说明这条记忆在主体认知中承担什么作用，**形成方式**说明该修订依据什么形成。

认知图式具有独立对象身份、修订和生命周期，但归属于记忆领域；它不是普通记忆的一个类型，也不单独建立顶层领域。

## 认知接受与事实正确性

接受一条 Memory 只确认它属于 Subject 的 cognition。将 basis 当作蕴含证明，会使真实来源上的错误解释无法被保存、纠正和分析；将新 revision 当作绝对更真，又会掩盖新解释可能引入的错误。系统因此精确记录实际 provenance 与 formation basis，另外表达支持、反驳和纠正等可修订判断。

Grounded 表示有显式 basis 且保留 provenance。错误的 grounded cognition 仍有真实谱系；后续 revision 可以纠正或持续误解。历史查询显示当时实际接受的内容，同时保留当前 permission/purge 边界。完整论证见[认知、形成依据与模型执行](12-cognition-basis-model-execution.md)。

## 记忆分类

一条记忆至少需要回答两个问题：

1. 它在主体认知中承担什么作用？
2. 它依据什么形成？

把这两个问题放进一个互斥类型，会丢失合法组合。

### 单一类型

可以把记忆分成“经历”“综合”“程序”等互斥类型。实现简单，但这些名称混合了认知内容和形成来源。

例如，“与 Alice 讨论复杂问题时，先给结论通常更有效”是一条程序经验。它既可能来自一次明确经历，也可能由长期多次互动综合形成。单一类型只能表达其中一个维度，另一个维度最终仍需额外字段补回。

### 任意标签集合

另一种做法是允许一条记忆挂任意多个标签。这可以表达组合，但标签本身没有稳定语义和约束。查询、形成和生命周期逻辑会逐渐依赖字符串约定，难以形成可执行规格。

### 两个独立属性

目标设计采用两个明确属性。

**认知角色**：

- **经历性记忆**：主体经历、接触或参与过什么；
- **陈述性记忆**：主体长期接受什么事实、判断或解释；
- **程序经验**：主体从经验中形成什么做法、步骤或策略性认识。

**形成方式**：

- **经历落地形成**：主要依据一个有界经历、观察事件或来源上下文，可以同时引用其他佐证；
- **综合形成**：跨多个认知对象、多个经历或多个独立来源形成。

二者可以任意形成语义合法的组合。程序经验既可以来自一次明确经历，也可以来自长期综合；陈述性记忆同样如此。

## 对象、修订与矛盾

认知角色更接近对象的稳定性质；形成方式描述某次修订的来源结构。具体哪些变化仍属于同一对象，由后续记忆规格给出判定规则，但必须保持两个分类维度彼此独立。

内容修订、生命周期和矛盾关系也分别表示：

- 同一认知的修正、澄清或重新解释形成新修订；
- 独立的新经历或新认知形成新对象；
- 矛盾是对象或修订之间的显式关系；
- 撤回表示领域所有者不再接受某项认知；
- 新修订成为当前版本时，旧修订仍保留在修订谱系中。

如果把矛盾直接当作生命周期状态，就会混淆“两个认知互相冲突”和“某项认知已经不再被接受”。

## 认知图式的归属

认知图式表达跨多个经历形成的结构性认识，例如：

> 在准备不足时，我往往会拖延并回避暴露自己的进展。

它需要表达适用范围、支持认知、反例、边界案例以及拆分和合并。这些操作并不适用于所有普通记忆。

### 作为普通记忆类型

这种方案可以复用记忆的修订和查询机制，但会迫使普通记忆对象承担支持集、反例、适用边界、拆分和合并等专属语义。随着功能增加，“统一类型”会退化成大量特殊分支。

### 作为独立顶层领域

这种方案边界最彻底，但会重复主体、证据、修订、可访问性、抑制、清除和检索等基础机制，并增加跨领域提案、事务和接口数量。认知图式的独立性还不足以支撑这种成本。

### 作为记忆领域的一等对象族

因此，认知图式拥有自己的稳定身份、修订和生命周期，但由记忆领域负责。它与普通记忆共享真正通用的认知基础，同时保留自己特有的支持、反例、边界、拆分和合并语义。

新增支持证据不必自动生成新的图式内容修订。只有结构性主张、适用范围或边界发生变化时才创建内容修订；单纯增加支持或反例只更新相应关系和对象并发版本。

## 研究依据

认知科学中的图式研究通常把图式描述为跨多个经历形成的关联结构，具有泛化和适应性，并不保留单一事件的全部细节。这里仅借助该研究界定问题结构；软件对象、权威和生命周期仍由 Nous Wave 自身的系统语义决定。
