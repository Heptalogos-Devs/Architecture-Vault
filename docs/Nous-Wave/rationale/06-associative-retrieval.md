# 联想检索机制

## 已确定的设计

联想检索属于可替换的检索服务机制。目标设计只固定以下语义约束：权威数据与服务拓扑分离；传播使用有限预算；来源谱系可去重；检索结果不会自我强化；负向和矛盾关系必须经过明确语义转换。

个性化 PageRank、竞争式传播、残差语义线索感知和主成分方法都属于研究方案，不进入目标设计本身。

## 对照顺序

任何高级联想算法都需要和无拓扑检索对照。建议至少比较：

1. 精确、实体、词项和稠密检索，不进行图扩展；
2. 有界个性化 PageRank 或同类扩散；
3. 保留充分状态的竞争式传播；
4. 必要时增加单跳或非回溯等更简单的图基线。

只有高级方案在相同过滤条件、种子和计算预算下，稳定改善目标工作负载的质量—成本关系，才适合作为默认实现。

## 个性化 PageRank 基线

典型形式为：

\[
p=\alpha s+(1-\alpha)P^{\mathsf T}p
\]

其中：

- \(s\) 是查询种子分布；
- \(P\) 是经过关系类型过滤、归一化和枢纽/扇出控制后的转移矩阵；
- \(\alpha\) 控制每轮回到种子的概率质量。

实际使用前仍必须先执行主体、访问控制和生命周期过滤，并记录预算和截断质量。矛盾、反例或其他带符号关系不能未经定义直接放入普通非负转移矩阵。

## 竞争式传播的状态合并

竞争式传播可以让状态携带前一节点、当前节点、剩余能量、动量或剩余路径预算等信息。如果两个状态未来允许的转移不同，就不能仅因为“前一节点和当前节点相同”而无损合并。

核心风险是：合并能量后只保留其中一条路径的剩余预算，会让另一部分能量借用本来不属于它的后续可达性，或者丢失本来合法的后续路径。

因此，后续状态表示必须覆盖所有会影响未来转移的变量；如果采用近似合并，则需要给出误差语义和实验边界。

## 残差语义线索

残差方法尝试从当前查询残差中寻找新的、近似独立的语义方向。如果选出的方向经过正交化形成列正交基 \(Q_j\)，残差可以按下式更新：

\[
r_{j+1}=r_j-Q_jQ_j^{\mathsf T}r_j
\]

新方向需要经过数值稳定的正交化处理，并依据剩余能量、候选质量和预算停止。

现有差分试验只验证受控条件下的数学转写一致性；真实检索收益仍需语料评测。

## 加权主成分分析

如果代表向量 \(x_i\) 代表 \(w_i\) 个重复样本，加权均值为：

\[
\mu=\frac{\sum_i w_i x_i}{\sum_i w_i}
\]

为了让奇异值分解保留重复样本对协方差的贡献，中心化矩阵的第 \(i\) 行应构造成：

\[
y_i=\sqrt{w_i}(x_i-\mu)
\]

然后对由这些行组成的矩阵执行奇异值分解或主成分分析。

只对均值加权，却直接把 \(x_i-\mu\) 作为分解矩阵的行，会丢失样本重复次数对协方差的影响。该数学问题应先修正，再讨论这种方法是否值得保留。

具体反例、随机试验数量和数值结果见 [算法研究证据](../research/ALGORITHM_EVIDENCE.md)。
