# 认知权威与行为权威

## 已确定的设计

Nous Wave 负责主体的长期认知：主体认为什么、如何理解自身和社会世界、希望什么。Heptalogos 负责行为与规范：主体是否以及如何对外行动、承担什么承诺、执行什么外部效果。

两侧共享稳定主体标识，但分别维护自己的领域状态。

## 不采用全局优先级链

一条类似“管理员 > 种子 > 人格 > 记忆 > 用户”的总优先级，会把不同问题混在一起。

例如：

- “这句话实际来自哪里？”属于来源与证据权威；
- “主体现在接受什么认知？”属于认知权威；
- “主体是否可以联系某人？”属于行为与规范权威；
- “是否永久清除某项数据？”属于管理权威。

管理员拥有清除权限，不意味着管理员的一句自然语言描述自动成为主体的自我认知。用户对自身事实的陈述可以成为高质量证据，也不意味着用户因此获得系统行为权限。

因此系统先判断输入属于哪种权威和哪个领域，再在该领域内核验操作者、证据、当前修订和权限。

## 认知种子与系统宪制

主体初始化材料经常混合两类内容：

- 主体关于自身的初始身份、倾向、价值和叙事；
- 产品安全、操作限制和不可绕过的行为规则。

前者属于自我领域的认知种子；后者属于宿主或 Heptalogos 的系统宪制。

这样，主体可以长期修订“我是谁、我喜欢什么、我如何理解自己”，却不能通过一次认知修订取消系统级安全或权限约束。

认知种子内部是否需要比普通自我修订更强的“构成性认知状态”仍是独立开放问题。在这个问题解决前，不应通过一个隐式的全局种子优先级代替正式语义。

## 目标与承诺

Nous Wave 动机领域中的目标表示主体希望实现的未来状态。Heptalogos 中的承诺和义务表示已经进入行为或规范体系的约束性状态。

典型路径为：

```text
长期价值或倾向
→ 愿望 / 目标 / 关切
→ 运行时激活
→ Heptalogos 审查与采纳
→ 承诺、任务或外部执行
→ 结果回执
→ Nous Wave 认知修订提案
```

如果一条记忆或目标文本可以直接执行工具或发送消息，认知内容就获得了越权行为能力。所有外部效果都必须经过 Heptalogos 的行为和规范审查。

BDI 与多智能体承诺研究为“愿望、目标、意图和承诺不属于同一状态”提供概念背景；Nous Wave 与 Heptalogos 的边界仍是本项目自己的工程权限设计。
