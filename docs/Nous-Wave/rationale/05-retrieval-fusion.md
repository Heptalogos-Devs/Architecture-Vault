# 检索计划与结果融合

## 已确定的设计

查询计划在看到候选结果之前固定检索通道、权重和预算。同一认知修订的多个服务视图先聚合为一个对象候选。拓扑检索作为普通检索通道参与融合，不使用查询计划之外的隐藏加分。

目标设计只固定这些性质。当前建议的参考融合方法是固定查询计划的加权倒数排序融合。

## 候选集合不能改变融合尺度

如果融合分母由“本批候选实际出现了哪些证据类别”决定，那么加入一个原本与 A、B 无关的候选 C，只要 C 带来新的证据类别，就可能改变 A、B 的分数尺度。

这意味着排名不再只由查询计划和 A、B 自身证据决定，还受到无关候选存在与否的影响。这样的规则不适合作为稳定检索语义。

## 原始分数直接相加

一种简单方案是：

\[
S(o)=\sum_f w_f s_f(o)
\]

但不同检索器的原始分数没有天然统一量纲。词项检索分数、余弦相似度、时间分数和拓扑分数不能在没有稳定校准的情况下直接比较。

## 每批候选归一化

可以对每个检索通道在当前候选集上的最小值、最大值或总和做归一化，再合并结果。实现简单，但归一化参数依赖当前候选集合，因此仍存在无关候选扰动问题。

## 固定计划的倒数排序融合

倒数排序融合只依赖各检索通道内部的排名，不要求不同检索器输出同量纲原始分数。

参考公式：

\[
S(o)=\sum_{f\in F}\frac{w_f}{k+r_f(o)}
\]

其中：

- \(o\) 是对象修订候选；
- \(F\) 是查询执行前已经固定的检索通道集合；
- \(w_f\) 是通道 \(f\) 的固定权重；
- \(r_f(o)\) 是对象 \(o\) 在通道 \(f\) 中的排名；
- 对象没有出现在某个通道时，该通道贡献为零；
- \(k\) 控制排名衰减速度，并在查询计划中固定。

如果需要把分数缩放到相对稳定区间，可以使用仅由查询计划确定的归一化：

\[
S_{\mathrm{norm}}(o)=
\frac{\displaystyle\sum_{f\in F}\frac{w_f}{k+r_f(o)}}
{\displaystyle\sum_{f\in F}\frac{w_f}{k+1}}
\]

分母与本次实际返回了哪些候选无关。

倒数排序融合是参考基线，不是不可替换的长期算法。若真实语料证明经过校准的分数融合或学习型融合在质量与成本上更好，只要仍满足目标设计规定的稳定性、对象级聚合和可解释查询计划约束，就可以替换。

Cormack, Clarke, Buettcher (2009), *Reciprocal Rank Fusion Outperforms Condorcet and Individual Rank Learning Methods*, SIGIR 2009.

## 多视图聚合

同一记忆修订可以拥有规范表示、段落表示、有来源约束的召回线索和其他服务表示。这些都是检索视图，不是独立证据票数。

推荐顺序为：

```text
视图命中
→ 每个检索通道内聚合到对象/修订
→ 每个对象在每个通道只形成一个排名位置
→ 跨通道融合
```

初始实现可以使用“该对象在该通道中的最佳视图排名”。如果要让第二、第三视图继续贡献，需要采用有上限的聚合，并验证切分更多段落不会无意义地提高对象权重。

## 拓扑检索

拓扑检索应像稠密检索或词项检索一样产生对象级排名，再进入统一融合阶段。

如果在融合完成后再叠加无法从查询计划解释的连续奖励，最终排序就失去明确来源。需要结果多样性时，应在最终选择阶段显式定义多样性目标，而不是把它隐藏在相关性分数中。
