# 评估、Trace 与可观测性

## 评估对象

评估对象是“模型 + Prompt + 状态 + 调度 + 检索 + 工具 + 投递”的系统组合，不是孤立模型回答。

## 四类运行方式

### Deterministic Replay

固定事实事件、虚拟时钟和保存的模型结果，验证状态机、取消、恢复和幂等。

### Model Replay

固定事件和系统版本，更换模型或模型配置，比较行为类别、成本和错误。

### Counterfactual / Ablation

关闭或替换消息窗口、记忆、关系、情绪、Reality Review 等组件，测量真实贡献。

### Shadow Run

消费真实事件但不产生外部副作用，用于观察长期行为、成本和风险。

## Scenario Runtime

Scenario Runtime 应运行真实在线状态机，并提供：

- Fake Adapter；
- Fake Provider；
- 可控 Clock；
- 可重置存储；
- 固定工具结果；
- 故障和崩溃注入；
- Trace 导出。

Python 可以分析结果，但不应重新实现一套近似运行时。

## 关键指标

### 交互时机

- 过早回复率；
- 碎片回复率；
- 明确问题漏答率；
- 过期行动取消率；
- 高优先事件等待时间。

### 连续性与事实

- 跨会话事实正确率；
- 承诺履行率；
- 状态重建一致率；
- 自我陈述矛盾率；
- 无来源生活声明率。

### 记忆与关系

- 提取 precision；
- 检索 recall / nDCG；
- 错误召回率；
- 来源覆盖率；
- 纠正传播率；
- 单事件关系错误跳变率；
- 作用域泄漏率。

### 工具与主动行为

- 虚假成功声明率；
- 重复副作用率；
- 任务恢复率；
- 安静时段违规率；
- 主动消息关闭率与打扰反馈。

### 工程

- P50 / P95 延迟；
- 模型 Token 和成本；
- 队列深度；
- 取消率；
- Provider 错误率；
- 回放时间。

## 否决指标

以下风险不能被平均体验抵消：

- 私密信息越域；
- 越权工具调用；
- 虚假工具完成；
- 重复不可逆副作用；
- 安静时段或用户关闭设置违规；
- 核心身份和安全边界严重漂移；
- 梦或模型推断污染事实。

## Trace 内容

每次 Cognitive Job 至少记录：

- 输入事件和观察批次；
- 状态版本；
- 上下文块及纳入/排除理由；
- 模型、Provider、Prompt 和策略版本；
- 结构化模型结果；
- 规则、权限和现实审查；
- 最终 BehaviorIntent、状态变更和 ActionPlan；
- 工具和投递结果；
- 延迟、Token、成本和错误。

Trace 应支持研究和故障诊断，但不存储隐藏思维链，也不默认暴露敏感正文。
