# 术语

| 术语 | 含义 |
|---|---|
| Evidence | 某个边缘实例实际观察或执行的原始证据 |
| Canonical Fact | 平台中立但保留来源的交互事实 |
| Observation Batch | 为一次认知聚合的相关事件 |
| Cognitive Job | 一次可持久、可取消、可恢复的认知任务 |
| Subject Snapshot | 某一时刻一致的主体状态版本集合 |
| Core Identity | 长期稳定的身份、价值和边界 |
| Living State | 当前活动、精力、情绪、目标和注意 |
| Memory | 可在未来影响认知的有来源经验表示 |
| Epistemic State | 主体知道、相信或掌握什么的视图 |
| BehaviorIntent | 主体决定采取的行为及社会目标 |
| ActionPlan | 已批准、可执行、可取消和可过期的步骤 |
| Capability | 具有权限、副作用、成本和结果语义的能力 |
| Commitment | 主体对某人形成的未来社会义务 |
| ProactiveOpportunity | 可能值得主动处理的触发，不等于行动许可 |
| Claim Ledger | 主体对不同对象作出的自我陈述历史 |
| Cognitive Commit | 对主体状态和行为计划的统一权威提交 |
| Trace | 一次行为的结构化输入、版本、决定和结果记录 |

命名以责任和不变量为准，不保证成为永久 API 或类名。
