## 什么时候新增

只有同时满足以下条件：

1. 影响多个模块、长期数据或部署方式；
2. 存在合理替代方案；
3. 未来成员很可能追问选择原因；
4. 改变它会造成明显迁移或兼容成本。

普通库选型、文件组织、小型重构和临时实验不写 Decision。

## 格式

```markdown
# D-NNN：标题

## 背景
## 当前选择
## 原因
## 约束或不意味着什么
## 代价
## 重新考虑条件
```

不要求状态审批。选择失效时可以：

- 直接更新同一文档并说明变化；
- 新建替代 Decision，并在旧文档顶部链接；
- 若只是实现细节变化，更新相关系统或工程文档即可。

旧版 ADR 由 Git 历史保留，仍有效的理由已经压缩进当前 Decision 和主题文档。
