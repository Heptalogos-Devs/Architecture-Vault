# 来源与研究笔记

## 来源类型

项目事实包括主仓库代码、测试、运行数据、Trace、故障和团队明确讨论。外部参考包括论文、标准、官方文档和相近系统。

外部参考只能说明机制可行、问题存在、评测可借鉴或风险需控制，不能证明整个参考架构适合 Heptalogos。

## 笔记格式

```markdown
# 来源名称
- 类型与时间：
- 链接或引用：
- 相关问题：
- 可借鉴机制：
- 不适用前提：
- 风险：
- 可能影响的文档或实验：
```

短资料直接追加；长资料放入 `notes/`。成熟结论写回主题文档，研究笔记不成为第二套权威知识树。

## 主要参考方向

- 长期记忆：提取、多会话、时间、更新、冲突和拒答；
- Agent 认知：观察、记忆、反思、计划和结构化动作；
- 工作流恢复：checkpoint、interrupt 和 durable execution；
- 安全：Prompt 注入、RAG 污染、工具操纵、最小权限和确认；
- 拟人交互：时机、边界、承诺、纠正和生活连续性。
