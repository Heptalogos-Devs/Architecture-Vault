# Research

本目录保存尚需实验验证的机制、指标、外部参考和研究结果。它不是架构权威来源。

## 内容

- [实验清单](Experiment-Backlog.md)
- [指标](Metrics.md)
- [研究问题](Research-Questions.md)
- [来源与笔记](Sources-and-Notes.md)

## 原则

- 每个实验先写假设和反证条件；
- 评估系统组合，不只测模型回答；
- 记录模型、Prompt、策略、数据和场景版本；
- 结果应回写相关概念或工程文档；
- 没有实际增益的复杂机制可以删除；
- 外部参考只提供机制和风险证据，不直接决定架构。

## 简单记录格式

```markdown
# 实验名称
## 问题
## 假设与反证
## 基线与变量
## 场景、指标和否决项
## 结果与限制
## 对系统的影响
```

不要求编号、审批或专门模板。
