# 假设与系统性风险

## 关键假设

| ID | 假设 | 反证信号 |
|---|---|---|
| A-01 | 消息时机对拟人感有独立贡献 | 固定即时回复与复杂调度无显著差异 |
| A-02 | 结构化持续状态比纯 Prompt 更稳定 | 状态模型增加漂移或没有提升 |
| A-03 | 带来源记忆能降低长期错误成本 | 修正机制复杂但错误率不降 |
| A-04 | 行为与表达分离可提高一致性 | 分层造成延迟且行为质量不升 |
| A-05 | 会话串行化足以控制大部分竞态 | 跨会话共享状态仍频繁冲突 |
| A-06 | 模块化单体能支持早期实验速度 | 模块边界导致大量内部协议负担 |

## 主要风险

- **伪精确状态**：情绪、信任等数值看似科学但没有可验证含义。
- **记忆污染**：模型推测被保存成事实，随后不断自我强化。
- **关系操纵**：系统为了互动率主动制造依赖或越过用户边界。
- **上下文反馈环**：状态影响生成，生成又被错误解释为状态证据。
- **平台语义丢失**：统一事件模型消除关键的平台特性。
- **隐式耦合**：上下文构建器成为读取所有数据库的超级模块。
- **评估投机**：针对固定 Judge 或脚本优化，真实体验下降。
- **研究系统生产化过早**：用户依赖尚无稳定性保证的行为。

## 风险控制方向

- 事实、推断和策略状态分表或分类型保存；
- 关键长期状态使用规则或人工批准更新；
- 提供删除、冻结、纠正和导出机制；
- 所有主动行为具备触发原因和取消入口；
- 使用历史回放与长期模拟检测反馈环。
