# 问题空间

## 为什么普通聊天机器人不足

传统聊天接口通常隐含四个假设：一次只来一条消息；每条消息都需要回复；对话以明确轮次推进；模型请求结束后系统没有持续状态。真实 IM 环境不满足这些假设。

### IM 是事件流，不是问答序列

用户可能连续发送三条消息，撤回其中一条，再引用上一小时的图片；群聊中同时有多人发言，机器人可能只应对其中一部分作出反应。任何把“最后一条文本”视为完整输入的系统都会丢失交互结构。

### 拟人感来自行为轨迹，而非单句风格

角色感并不只来自词汇、语气或口癖，还来自：

- 对过去经历的连续引用；
- 对关系边界的稳定维护；
- 对消息时机的选择；
- 是否履行承诺；
- 工具行动与语言表达的一致；
- 在相似情境中的稳定倾向。

### 长期状态会积累错误

持续系统会把一次误判放大为长期偏差。例如错误提取的用户偏好、过快增长的亲密度、未取消的提醒、重复执行的工具。长期运行要求系统具有来源、版本、冲突和修正机制。

### 自主性与打扰风险同时增加

主动行为越强，越可能带来价值，也越可能形成骚扰、越权或不合时宜。系统需要把“能够主动”与“允许主动”分开。

## 核心张力

| 张力 | 一端 | 另一端 |
|---|---|---|
| 真实性与效率 | 等待、犯小错、非即时 | 快速、完整、工具化 |
| 连续性与隐私 | 记住更多 | 最小化保存和暴露 |
| 自主性与控制 | 自行计划和发起 | 用户可解释、可关闭 |
| 个性化与稳定性 | 因人而异 | 不过度迎合或人格漂移 |
| 模块化与整体体验 | 清晰边界 | 上下文和行为需要协同 |
| 研究灵活性与工程纪律 | 快速试验 | 可回放、可维护、可比较 |

## 系统问题的最小表达

```text
观察世界发生的事件
→ 建立当前情境
→ 更新持续状态
→ 决定是否以及如何行动
→ 执行行动并观察结果
→ 将结果转化为新的事实与经验
```
