# 术语与命名

> [!note]
> 下列名称均为工作名称。术语确定前，优先讨论责任和不变量，而不是争论模块名字。

| 工作名称 | 暂定含义 | 容易混淆的概念 |
|---|---|---|
| Event / 事件 | 对已发生事实的不可变描述 | 命令、状态、通知 |
| Observation Batch / 观察批次 | 为一次决策聚合的一组事件 | 单条消息、会话摘要 |
| State / 状态 | 某一时刻的可查询投影 | 记忆、Prompt |
| Persona Definition / 角色定义 | 相对稳定的身份和行为约束 | 当前情绪、说话风格模板 |
| Runtime State / 运行状态 | 短期变化的注意、能量、目标等 | 人格定义 |
| Relationship State / 关系状态 | Agent 与对象之间的持续关系视图 | 用户画像、聊天频率统计 |
| Memory / 记忆 | 可在未来影响决策的持久经验表示 | 原始聊天记录、知识库 |
| Behavior Intent / 行为意图 | 决定做什么及为何做 | 最终文本、工具参数 |
| Action Plan / 行动计划 | 可执行、可取消、可审计的动作序列 | 语言回复 |
| Capability / 能力 | 系统可提供的感知或执行能力 | 单个函数工具 |
| Commitment / 承诺 | 需要未来履行或检查的持久义务 | 普通记忆、定时器 |
| Wake-up / 唤醒 | 进入行为决策的条件满足 | 进程唤醒、模型调用 |

## 命名判断规则

- 能重建的是投影，不能重建且描述已发生事实的是事件。
- 期望未来发生的是命令或计划，不是事件。
- 影响行为但不等于事实的，是策略或状态。
- 不要用“memory”泛指数据库中所有历史数据。
