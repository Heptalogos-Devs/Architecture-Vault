# 记忆与知识边界

## 数据分类

| 类型 | 含义 |
|---|---|
| Event Fact | 已发生的外部或系统事实 |
| Working Memory | 当前 Cognitive Job 的临时信息 |
| Episodic Memory | 对一段经历的有来源压缩 |
| Person Fact | 主体对某人的当前认识 |
| Relation Memory | 共同经历、边界和未完成事项 |
| Semantic Memory | 主体已经形成的稳定知识 |
| Autobiographical Memory | 与自我身份相关的经历 |
| Procedural Memory | 工具和行为的经验 |
| Affect Association | 低权威的情绪联想 |
| Commitment | 未来义务，属于任务约束而非普通记忆 |

原始事件、长期记忆、用户画像和索引不能混为一体。

## 记忆记录

稳定记忆至少包含：

- 类型和主体；
- 内容或结构化谓词；
- 来源事件；
- epistemic origin；
- observed / valid 时间；
- 置信度；
- 显著性；
- 作用域和敏感度；
- active / disputed / superseded / deleted 状态；
- 冲突、替代和提取器版本。

## 写入生命周期

```text
事件或日记
→ MemoryCandidate
→ 权限与作用域检查
→ 来源和证据分类
→ 去重、冲突与时间检查
→ merge / activate / keep candidate / reject
```

模型生成的候选不等于事实。撤回、纠正、敏感策略和弱推断都可能阻止激活。

## 纠正与遗忘

应区分：

- 事实有效期；
- 来源可信度；
- 检索激活度；
- 主观清晰度；
- 数据保留政策。

“衰减”不意味着删除事实。用户纠正通常追加新的证据和替代关系，而不是无痕覆盖历史。

## 检索

检索顺序：

1. 作用域、人物、时间、敏感度和状态硬过滤；
2. 结构、全文、语义、关系、任务和时间信号评分；
3. 冲突和不确定性惩罚；
4. 去重、多样化和 Token 预算打包；
5. 生成 Provenance Manifest。

纯向量相似度不能承担完整检索。早期优先 SQL + FTS，向量和 reranker 通过实验决定。

## 知识边界

基础模型的潜在知识不等于主体知识。Epistemic State 描述主体对某个领域：

- 是否听说；
- 熟悉程度；
- 来源；
- 最近使用和学习；
- 可表达深度；
- 不确定性；
- 是否允许搜索或请教。

面对越界问题，主体可以：

- 承认不知道；
- 以有限深度回答；
- 搜索或调用专家能力；
- 明确区分自身认识和外部检索结果。

## 在线与离线分工

TypeScript 在线内核拥有记忆权威状态、作用域、冲突、纠正和删除。Python 可以实验候选提取、情节分割、Embedding、重排和压缩，但只能返回带来源的候选或评分。

## 开放问题

- 最小记忆类型集合；
- 情节分割和合并的判断；
- 时间、关系、显著性和访问次数的权重；
- Epistemic State 的领域粒度；
- 哪些记忆允许自动激活，哪些需要人工确认。
