# 整体架构与模块合同

[项目宪纲](../项目宪纲.md)是需求权威。两个产品独立安装、拥有各自数据库、安装身份、权限和生命周期，以正式接口组成同一主体。

## 产品与所有权

| Heptalogos：MaiBot Fork 与主体内核 | Nous Wave：Python 应用与 Native 计算 |
|---|---|
| 主体在产品中的创建、运行、Nous 绑定和稳定逻辑 Subject ID | 主体的认知供给、知识、Memory、Episode、Journal、Self、Social、LanguageConvention 和 Motivation |
| 世界设定、NPC 客观身份与行动、世界时钟和映射、日历、已实现生活史 | 主体对自己、人物、NPC、事件、世界和未来的认识、来源及修订 |
| 平台账号、会话、原始消息、附件、发送回执 | 人物资料、社会关系及依据证据形成的跨平台身份对应 |
| 心情、精力、前台注意、Reactor、行动选择、已采纳追求、计划、承诺和执行结果 | 长期价值与人格倾向、语言惯例、愿望和关切的形成与检索 |

一个逻辑主体跨群聊、平台与执行者使用稳定的 Subject ID。Hept 保存平台提供的账号和消息事实，Nous Social 依据明确线索建立人物与平台身份的认识；客观 NPC 身份与主体对 NPC 的认识各归其所有者。两边通过受限接口引用主体与实际来源，不直读彼此数据库或维护两份认知真相。

## Hept：生活、注意与行动

Heptalogos 直接继承 MaiBot 的通信、原始多模态消息、插件接口和市场、模型与 Prompt 资源、内置工具、学习能力及 WebUI/Dashboard。主体 Reactor 将世界事件、日历节点、设备通知、群聊和私聊、人物、任务结果与内部动机组织为活动机会。一个主体有统一主观前台，能够扫视、中断并恢复；日程、后台任务、媒体保全和多平台会话可并行。IM 是生活中的通信途径，生活可在无消息时随世界时间推进，并按重要事件分段形成历史。

主体审议是否注意、查阅、交往、休息、探索、委派或行动；表达角色表达已采用的意图，工具与平台执行并记录实际结果。插件可调用的正式接口、角色与事件语义继续提供。OpenClaw 可按需承担专业执行任务。

## Nous：来源与长期认知

Python 拥有领域、模型、授权、事务及 CLI、HTTP、MCP、Python SDK；现有 Native 实现承担 VCP、NousQL 等计算热点，后续按收益和维护成本选择适合的语言或成熟库。材料原件及表示、精确来源和实际观察支撑认知形成、修订、检索与维护。查询按同一请求的读取视图组织时间和来源，并在返回时遵守当前权限、清除及生命周期；认知对象清除及其权威依赖、运行时引用和投影失效应保持一致，共享材料依有效引用处理。

A-Memorix 现有检索、画像、Episode、导入、图谱、维护、纠错、Bundle、图片和管理接口构成完整功能基线。其公共合同由边界适配器提供，Nous 领域与数据库保持自己的模型；Hept 的记忆消费者和 Dashboard 通过同一认知权威工作。外部知识资源由可选适配器访问，原材料及外部系统各有生命周期所有者。

## 时间、实际感知与协作

Hept 持有世界时钟与映射，Nous 以有来源的时域记录事件发生、主体接触、认知形成、内容适用和实际记录五轴。保存原件、通知、扫视、真正阅读、模型实际接触、认知形成、采用行为和物理发送结果是不同事实。Hept 提供主体实际接触的消息、已实现经历、工具结果、真实发言与反馈；Nous 返回适合主体、用途与听众的记忆、人格、社会关系、知识和动机。

黑话、表情图片/GIF、音频梗等社会符号具有载体、感知或描述、表达的情绪或含义、使用对象和场景、社会范围及实际经历。媒体客观内容与社会含义分别保存；Nous Social / LanguageConvention 负责社会语义及其来源和演化，Hept 在当前情境下运用 MaiBot 的学习、表达和媒体能力。

## 当前基线

Hept `main` 是未经主体内核改造的 MaiBot Fork；Reactor、世界与 Nous 连接仍待实现。Nous `main` 为 Python/Native 实现，模型角色注册尚未完成应用组装；A-Memorix 完整消费者和其他领域能力仍待接通。具体状态由各产品文档维护。
