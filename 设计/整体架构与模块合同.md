# 整体架构与模块合同

[项目宪纲](../项目宪纲.md)是需求权威。两个产品独立安装、拥有各自数据库、安装身份、权限和生命周期，以正式接口组成同一主体。Nous 的认知运行与交互细节见 [Nous 原生认知与交互](Nous原生认知与交互.md)。

## 产品与所有权

| Heptalogos：MaiBot Fork 与主体内核 | Nous：Python 应用与 Native 计算 |
|---|---|
| 主体的创建、运行、稳定逻辑身份及与 Nous 认知域的绑定 | 该主体的认知域、知识、Memory、Episode、Journal、Ego、Social、LanguageConvention 和 Motivation |
| 世界设定、NPC 客观身份与行动、世界时钟和映射、日历、已实现生活史 | 主体对自己、人物、NPC、事件、世界和未来的认识、来源及修订 |
| 平台账号、会话、原始消息、附件、发送回执 | 人物资料、社会关系及有来源的跨平台身份认识 |
| 心情、精力、前台注意、Reactor、行动选择、已采纳追求、计划、承诺和执行结果 | 长期价值与人格倾向、语言惯例、愿望和关切的形成与检索 |

一个逻辑主体跨群聊、平台与执行者保持稳定身份。Heptalogos 保存平台实际提供的账号与消息，Nous Social 根据交往与证据形成认识。客观世界中的 NPC 身份及行为归世界所有者，主体对 NPC 的理解归 Nous。

**Nous Namespace 是完整的认知数据域。Subject 是启用主体认知时与之绑定的稳定个体身份；Ego、Social 等能力在同一数据域内启用。** 普通知识库只需 Namespace；多个独立主体各使用自己的认知域。临时执行者、会话及所认识的人拥有各自身份和访问范围，无需拥有另一份完整的认知域。两产品以授权、身份与实际来源引用协作。

## Hept：生活、注意与行动

Heptalogos 直接继承并发展 MaiBot 的通信、原始多模态消息、插件接口与市场、模型和 Prompt 资源、内置工具、学习能力及 WebUI/Dashboard。主体 Reactor 将世界事件、日历节点、设备通知、群聊和私聊、人物、任务结果与内部动机组织为活动机会。

一个主体拥有统一主观前台，能够扫视、中断和恢复。日程、后台任务、媒体保全及多平台会话可并行；世界生活在无即时消息时照常推进，并在重要节点形成已实现历史。

主体审议是否关注、交往、休息、探索、委派或行动；表达角色根据已采纳意图自然措辞，工具和平台执行并记录实际结果。插件继续调用正式的 MaiBot 兼容接口与真实事件位置。OpenClaw 可以按需承担专业执行任务。

**Heptalogos 自己拥有 Nous 宿主集成。** MaiBot Hook、原始消息接线、Dashboard、模型调用位置和工作上下文消费均在 Heptalogos 的产品源码内实现，调用 Nous 正式 SDK。Nous 本体可独立安装和使用。

## Nous：认知与长期工作

Nous Memory 管理记忆、Episode、Journal、来源与认知修订；Nous Wave 组织词项、向量、概念图、VCP、候选融合与重排序。NousQL 是通用认知查询语言，由 Wave 执行检索。Nous Ego 管理自我认识、人格种子与自我叙事；Nous Social 管理人物、群体、关系、跨平台身份认识与社会交流惯例；Nous Context 管理当前认知工作与模型实际消费；Nous Motivation 管理愿望、关切及期望状态。

Python 持有领域语义、模型调用、权限、事务、配置与应用生命周期；Native 承担 VCP、NousQL 等必要的高性能计算。材料原件、派生表示和实际接触共同支撑认知形成、修订和检索。认知权威与可重建索引分离。领域操作由明确所有者完成来源、状态和后续工作；CLI、MCP、HTTP 与 SDK 复用同一正式操作。

深度集成时，Nous 在宿主实际模型调用前准备当前适用的自我、关系、记忆和工作认知，并在调用后接纳真实输入、输出与反馈。工作集、Steward、Journal、离线认知及缓存续接属于认知运行时；模型承担有界的语言理解与生成任务，程序掌握预算、来源、状态和持久操作。

A-Memorix 既有记忆、画像、Episode、图谱、维护、纠错、导入、Bundle、图片及管理功能构成 Nous 原生能力的覆盖基线。**独立兼容适配器通过 Nous SDK 转换 A-Memorix 公共协议。** 兼容工具和 RPC 的专有合同留在适配器中；Nous 的本体、模型与数据库维持原生认知语义。Heptalogos 通过其自身的宿主集成使用该能力。

## 时间、实际感知与协作

Heptalogos 持有世界时钟与时间映射，Nous 以有来源的时域记录事件发生、主体接触、认知形成、内容适用和实际记录五轴。保存原件、产生通知、扫视、阅读、模型实际接触、形成认识、采用行动和发送结果是不同的事件。

Heptalogos 提供主体实际接触的材料、已实现生活、工具成果、真实表达与行为反馈；Nous 返回适合主体、当前用途和听众的记忆、人格、社会关系、知识和动机。主体获知资料、后台执行者取得材料以及创作者提供设定，保留各自来源身份。

黑话、文字称呼、表情图片/GIF、音频梗等属于社会交流符号。符号具有载体、内容描述、交流含义、情绪或意图、对象、适用情境及社会使用经历。Nous Social 与 LanguageConvention 负责语义与演化；Heptalogos 在实际交往中使用 MaiBot 的媒体、语言学习和表达能力。
