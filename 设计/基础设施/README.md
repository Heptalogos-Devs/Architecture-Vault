# 基础设施详规

所有专题采用[整体架构](../整体架构与模块合同.md)的模块名和唯一owner。共享mechanics位于普通`@nous-wave/platform`发行包；产品各自创建实例和数据库，领域定义业务结构、授权和采用规则。

| 专题 | 直接消费者与交付 |
|---|---|
| [共同值与调用上下文](共同值与调用上下文.md) | 全部入口/领域；Ref、来源身份、时间、Actor/Consumer、Policy、Money、Problem、幂等 |
| [安装与生命周期](安装与生命周期.md) | Bootstrap/Host/Subject；目录、独立启动、服务、运行依赖、离线管理 |
| [配置与生效](配置与生效.md) | 所有模块；Schema/默认/四层稀疏覆盖、修订、当前生效与通知 |
| [存储事务与缓存](存储事务与缓存.md) | 全部owner；PostgreSQL/Kysely/DBOS、回执、Blob、时间/JSON、索引与缓存 |
| [身份权限与密钥](身份权限与密钥.md) | 管理/Subject/Worker/原生/效果；Better Auth、限定委派、SecretRef、Recovery |
| [网络与外部资源](网络与外部资源.md) | 模型/资料/工具/浏览器/渠道；Undici、代理、TLS、流、范围与连接生效 |
| [模型供应与调用](模型供应与调用.md) | 全部Role；多模型族、路由/参数、实际调用、预算、费用、恢复与原生接缝 |
| [Prompt与上下文](Prompt与上下文.md) | Role/Context/原生调用；资源/版本/覆盖/渲染/预览、实际完整输入与消费 |
| [时间与调度](时间与调度.md) | Query/认知、World/Calendar/Life/Task；分段时钟、捕获、五轴/历史、DST、离线和唤醒 |
| [媒体与材料基础](媒体与材料基础.md) | 完整消息/材料/感知/表达；Blob、区域、派生、来源限制、物理回执 |
| [检索服务与认知消费者](检索服务与认知消费者.md) | NousQL/Context/成长/维护；数据/索引/模型/参数、Rust数值复用、更新与诊断 |
| [观测错误与诊断](观测错误与诊断.md) | 全部真实执行；Pino/OTel/DBOS、安全错误、本地管理和费用关联 |
| [管理呈现与扩展](管理呈现与扩展.md) | 独立/联合Console、产品能力；AstrBot组件、Cordis、原生Tools/MCP/Skills/插件 |
| [API、CLI、SDK与i18n](API、CLI、SDK与i18n.md) | 所有用户入口；正式合同、OpenAPI/Client、CLI/MCP、流、错误与语言资源 |
| [数据生命周期与发行](数据生命周期与发行.md) | 各owner/安装/原生运行；主体包、备份/恢复/清除、发行/更新 |

操作路径集中在[目录](../../公开操作目录.md)，配置和资源示例在[示例](../../示例/README.md)。[施工顺序](../../施工顺序.md)按依赖安排实际交付；[能力纠偏](../能力保全与现有代码纠偏.md)指定现有代码的替换位置。每项基础能力都有管理入口、失败/恢复和数据生命周期，不要求另一个领域先实现完整业务才能使用。
