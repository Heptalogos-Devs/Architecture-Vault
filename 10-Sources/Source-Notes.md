## 已核对的机制

- MaiBot：消息进入 Planner 的调度、回复必要性、记忆内核和跨平台身份演化风险；
- AstrBot：平台抽象、事件队列和有序 Pipeline；
- VCPToolBox：持续存在、上下文流入、工具生命周期和分布式能力；
- WaifuBot：角色、媒体、工具、权限和管理面的功能覆盖；
- AI Agent Book：上下文、记忆、异步工具和评估方法；
- NapCatQQ：QQ 协议端定位和边缘能力。
- LLBot：OneBot 11、Satori 与 Milky 的可替换 QQ 协议实现候选。
- Milky：QQ 应用接口规格、通信方式与机器可读协议定义。
- NcatBot：NapCat/OneBot 上层 Python SDK；只作为快速连通参考，不作为核心运行时。
