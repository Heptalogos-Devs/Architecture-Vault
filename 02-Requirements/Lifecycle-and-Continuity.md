# 生命周期与连续性

## 连续性的对象

连续性不是一个总开关，而是多个对象的生命周期协调：

| 对象 | 生命周期 | 结束条件 |
|---|---|---|
| 单条事件 | 永久事实或按治理删除 | 数据政策 |
| 观察窗口 | 秒到分钟 | 决策触发、话题边界、超时 |
| 会话运行单元 | 活跃期间 | 长期空闲后休眠 |
| 当前话题 | 分钟到小时 | 语义转移或显式结束 |
| 运行状态 | 分钟到天 | 衰减、事件更新、重置 |
| 关系状态 | 周到长期 | 证据更新、用户纠正 |
| 承诺与任务 | 直到履行、取消或过期 | 明确终态 |
| 长期记忆 | 有效期不定 | 替代、失效、删除、衰减 |
| 角色定义版本 | 发布周期 | 新版本替代但保留历史 |

## 跨边界连续性

- **跨消息**：连续输入和打断处理。
- **跨会话**：任务、关系和相关记忆持续。
- **跨平台**：同一人物和 Agent 的身份映射。
- **跨模型**：模型切换不改变领域状态语义。
- **跨进程**：调度、任务和 Outbox 可恢复。
- **跨版本**：能够按旧 Prompt、策略和 schema 回放。

## 不应连续的内容

- 临时推理草稿；
- 未验证的模型猜测；
- 仅为本次生成构造的 Prompt 文本；
- 已过期工具列表；
- 私聊敏感信息到群聊的自动传播。
