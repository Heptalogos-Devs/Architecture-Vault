# 安全、隐私与控制

## 控制面级别

1. **系统策略**：禁止或限制某类能力和数据流。
2. **Agent 策略**：角色可以偏好不使用某些能力，但不能突破系统策略。
3. **会话策略**：群聊、私聊和特定会话的规则。
4. **用户设置**：记忆、个性化、主动频率、安静时段。
5. **单次确认**：高风险工具和敏感数据使用。

## 隐私作用域

```text
private-to-user < direct-conversation < group < public
```

数据只允许向更窄或等价作用域流动。向更宽作用域注入必须有显式授权或不可识别化处理。

## 防止情感操纵

- 不以维持互动率为由隐瞒事实或制造紧迫感；
- 不将用户沉默解释为关系惩罚；
- 不通过记忆和关系状态制造负罪感；
- 主动行为应允许关闭并记录触发依据；
- 关系模型不得成为绕过安全策略的信任分数。

## 工具安全

- 感知、执行、沟通和协作能力分级；
- 写操作默认比读操作要求更严格的确认；
- 沙箱不等于无风险，仍需网络、文件和凭据边界；
- 工具返回视为不可信输入，需防提示注入和数据污染。
