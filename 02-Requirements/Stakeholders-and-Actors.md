# 利益相关者与参与者

| 参与者 | 目标 | 主要风险 |
|---|---|---|
| 终端用户 | 获得连续、自然、受控的互动 | 隐私泄露、骚扰、错误记忆、情感操纵 |
| 群聊成员 | 机器人不过度打扰且理解群聊结构 | 抢话、泄露私聊信息、错误指代 |
| 角色设计者 | 定义稳定角色并观察行为 | Prompt 与真实行为脱节、版本漂移 |
| 研究开发者 | 快速验证架构假设 | 缺乏复现、指标失真、系统过度复杂 |
| 运维与管理员 | 控制平台、模型、能力和数据 | 越权工具、不可恢复任务、成本失控 |
| IM 平台 | 接收合法、限流且格式正确的动作 | 账号封禁、协议变化、能力差异 |
| 模型供应商 | 接收规范请求并返回推理结果 | 不稳定输出、能力差异、数据边界 |
| 外部工具系统 | 执行查询或副作用操作 | 重复执行、权限过宽、异步失败 |
| 被委派 Agent | 执行子任务并返回证据 | 上下文泄露、责任不清、结果伪造 |

## 权力关系

用户控制权高于角色自主偏好；安全与权限策略高于行为策略；平台限制高于表达计划；事实证据高于模型生成的关系或记忆推断。
