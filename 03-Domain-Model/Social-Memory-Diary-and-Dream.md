# 社交关系、记忆、日记与梦

- **状态**：Concept
- **主题**：关系差异、记忆类型、反思和非事实联想

## 1. 社交关系系统

主体面对不同的人，应表现出不同的：

- 信任程度；
- 情绪暴露；
- 回复优先级；
- 语言风格；
- 幽默方式；
- 边界；
- 信息披露；
- 容忍和冲突模式。

这不是附加修辞，而是正常人际行为。

### 1.1 关系状态

每个关系对象可以维护：

- 熟悉度；
- 信任；
- 好感；
- 尊重；
- 依赖；
- 紧张；
- 怨气；
- 责任感；
- 边界；
- 关系类型。

关系类型可作为初始模板，但不能代替动态关系。

### 1.2 关系的变化

关系状态应由长期互动和重要事件逐渐变化。  
单次生成不应任意把普通朋友升级为亲密关系，也不应无依据地清除长期矛盾。

## 2. 记忆系统不是单一向量库

至少应区分以下记忆。

### 2.1 情景记忆

具体发生过的事情，包括时间、人物、上下文和结果。

### 2.2 语义记忆

从多次经历中抽象出的稳定认识，例如：

```text
某人不喜欢被连续追问。
```

### 2.3 自传记忆

与主体身份和人生叙事密切相关的重大经历。

### 2.4 程序性记忆

主体如何做某类事情，例如如何安慰某人、如何道歉。

### 2.5 工作记忆

当前正在处理的会话、计划、草稿和召回结果。

### 2.6 情绪记忆

对某个人、话题或场景形成的情绪反应，即使具体事实已经模糊。

## 3. 记忆召回

召回不能只依赖语义相似度。

可能需要综合：

- 语义相关性；
- 人物关联；
- 时间接近度；
- 情绪一致性；
- 事件重要性；
- 重复次数；
- 当前关系；
- 当前目标；
- 未完成事务。

人类联想常常由人物、情绪或未完成目标触发，而不是由字面相似度触发。

## 4. 记忆与原始记录分离

原始记录保存“实际发生了什么”；  
记忆保存“主体后来如何保留和理解这件事”。

记忆允许：

- 压缩；
- 遗忘；
- 偏差；
- 主观重构。

但原始事件不应因此被改写。

## 5. 日记系统

日记不是聊天记录摘要，而是主体对经历的二次理解。

日记可以：

- 选择重要事件；
- 记录情绪变化；
- 提炼关系认识；
- 标记未解决问题；
- 形成长期自我叙事；
- 强化或弱化某些记忆。

日记属于主观记忆，不应被当作客观事实。

## 6. 梦系统

梦可以被定义为：

> 低事实约束的离线联想与记忆重组。

梦可以使用：

- 当天经历；
- 长期焦虑；
- 关系张力；
- 遥远记忆；
- 未完成目标；
- 随机象征。

其作用可能包括：

- 产生非平凡联想；
- 形成隐喻；
- 影响第二天情绪；
- 提供创意；
- 加深某些主观认识。

## 7. 梦与现实必须隔离

所有内容应标注来源，例如：

```text
observed
inferred
remembered
imagined
dreamed
```

`dreamed` 内容可以影响：

- 情绪；
- 联想；
- 创作；
- 主观叙事。

但不能直接作为：

- 某人真实说过什么；
- 某件事实际发生过；
- 关系变化的客观证据。

## 8. 反思系统的角色

日记和梦都属于离线认知过程。  
它们不直接处理实时消息，而是在特定时间重新组织经历。

因此主体不仅会“回应事件”，还会在事件结束后继续改变。

## 9. 实现参考

早期可以先实现：

- 事实事件存档；
- 人物相关记忆；
- 简单重要度；
- 每日摘要式日记；
- 梦内容独立存储并明确标记为非事实。

不要在早期让日记或梦直接修改核心人格和现实时间线。
