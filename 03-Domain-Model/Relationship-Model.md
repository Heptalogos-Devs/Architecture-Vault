# 关系模型

## 关系不是单一分数

一个总“亲密度”容易隐藏不同事实。建议初始模型拆成：

- 互动事实：频率、最近时间、共同会话、称呼使用；
- 明确偏好：用户要求的边界、称呼和沟通方式；
- 共同经历：双方都参与且具有来源的情节；
- 未完成事项：答应、等待或需要跟进；
- 策略状态：允许的主动频率、默认正式程度；
- 可选抽象：熟悉程度、信任边界，但更新必须受限。

## 作用域

```text
Agent ↔ Person
Agent ↔ Conversation/Group
Agent ↔ Person within Conversation
```

三者不能自动等价。群聊中的熟悉不等于私聊亲密，私聊秘密不属于群体关系。

## 更新原则

- 强证据优先于模型推断；
- 正负变化均有速率限制；
- 用户明确边界立即生效；
- 抽象关系字段不能直接作为工具权限；
- 关系状态必须可解释为事实或政策的结果。

## 待验证问题

- 是否真的需要情感价度、亲密度等连续变量；
- 关系状态对行为选择的增益是否超过简单偏好和互动历史；
- 如何避免迎合性模型把礼貌误判为亲密。
