# 人工主体愿景与总体模型

- **状态**：Concept
- **主题**：系统定位、总体目标与模块边界

## 1. 背景

Heptalogos 的长期目标并非构建高吞吐量客服机器人、多租户聊天平台或“每个会话一个 Agent”的自动回复系统。

其目标是模拟一个持续存在的真人主体：

- 有相对稳定的人格；
- 生活在一条持续流动的虚拟时间线上；
- 有每天变化的心情、精力和压力；
- 同不同的人维持不同的社会关系；
- 会记住、遗忘、误解、联想和反思；
- 并非随时在线，也并非对所有领域都无所不知；
- 会通过 IM 平台阅读、等待、打断、回复或不回复。

IM 平台只是该主体的外部行为界面，而不是主体本身。

## 2. 核心定义

更准确的系统定义是：

> 一个拥有持续身份、主观时间、社会关系、认知边界、情绪和自传记忆，并通过通信平台参与外部世界的人工主体。

该主体应表现为同一个人，而不是一组松散的 Prompt、工具和独立模型调用。

## 3. 三个基本层次

### 3.1 稳定身份层：他是谁

负责长期稳定的内容：

- 身份事实；
- 人格基线；
- 价值取向；
- 语言风格；
- 长期偏好；
- 行为边界；
- 自我叙事。

可统称为：

```text
Core Identity
```

### 3.2 动态生命状态层：他现在怎样

负责随时间变化的内容：

- 当前情绪；
- 精力、压力和社交意愿；
- 当前活动；
- 日程和时间位置；
- 当前目标；
- 注意力；
- 是否适合阅读或回复消息。

可统称为：

```text
Living State
```

### 3.3 认知与行为层：他如何理解并行动

负责一次事件到行为之间的过程：

- 解释事件；
- 召回记忆；
- 识别关系；
- 检查知识边界；
- 判断是否回复；
- 决定何时回复；
- 生成行为和语言；
- 更新情绪、关系、记忆与生活事实。

可统称为：

```text
Cognitive Reactor
```

## 4. 建议的总体模块

未来系统可能包含：

```text
Core Identity
Emotional State
Virtual Schedule
Lived Timeline
Social Relations
Epistemic State
Memory System
Diary System
Dream System
Goals
Attention Scheduler
Cognitive Reactor
Interaction Gateway
```

这些模块共同服务于一个主体，而不是各自扮演一个独立主体。

## 5. 闭环

系统应形成以下持续闭环：

```text
外部事件
  ↓
主体解释
  ↓
情绪、关系、记忆与目标参与
  ↓
形成行为
  ↓
行为改变外部关系与内部状态
  ↓
形成新的经历
```

这一区别决定了系统不应只做“当前上下文内的合理回答”，而应维护跨时间、跨会话、跨平台的一致存在。

## 6. 非目标

当前设想不以以下目标为优先：

- 最大并发吞吐；
- 每个会话独立 Agent；
- 始终即时回复；
- 对所有问题给出最正确、最完整的答案；
- 让每个模块各自独立调用模型并直接修改系统状态。

## 7. 实现参考

实现上可采用模块化状态域和事件驱动协调，但重要的不是模块数量，而是保证：

1. 只有一个主体；
2. 状态具有持续性；
3. 所有行为有可解释来源；
4. 事实、主观解释和想象严格区分；
5. 语言输出能够对后续世界状态产生约束。
