# 工具、Agent 与能力系统

## 能力分类

- **感知能力**：读取消息、网页、文件、知识和设备状态。
- **执行能力**：写文件、发邮件、创建日程、控制设备。
- **沟通能力**：发送消息、反应、通知和结构化卡片。
- **事件能力**：注册定时器、监控条件和外部订阅。
- **协作能力**：委派给其他 Agent 或请求人工处理。
- **常驻服务**：索引、监听、下载和媒体处理。

## CapabilityDescriptor

除函数 schema 外，还应包含：副作用、权限、数据范围、风险、预计耗时、成本、幂等、可取消、重试、确认和平台支持。

## 工具选择

不要向模型一次暴露全部工具。先由能力发现根据行为意图、权限和环境筛选少量候选，再生成模型可见描述。

## 子 Agent

子 Agent 是一种执行后端，而不是默认架构单位。委派必须说明：目标、上下文边界、可用能力、预算、终止条件和结果证据。子 Agent 结果作为事件返回，主行为策略负责如何向用户表达。

## 安全边界

通用执行器适合低风险和沙箱场景；生产写操作、隐私数据和平台账号控制应使用专用能力与细粒度审计。
