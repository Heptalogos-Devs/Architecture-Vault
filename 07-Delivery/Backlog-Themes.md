# Backlog 主题

- EPIC-EVT：事件契约、原始载荷、去重和回放；
- EPIC-IDN：平台身份、人物绑定和成员关系；
- EPIC-CNV：Mailbox、窗口、唤醒、打断和背压；
- EPIC-STA：状态投影、版本和重建；
- EPIC-BEH：情境、行为、表达和验证；
- EPIC-MEM：候选、来源、冲突、检索和删除；
- EPIC-CAP：能力描述、权限、任务和异步结果；
- EPIC-SCH：调度、承诺、主动机会和打扰预算；
- EPIC-OUT：Outbox、投递、回执和降级；
- EPIC-EVAL：场景、虚拟时间、指标和报告；
- EPIC-GOV：配置版本、数据治理和管理操作。

任务拆分时应引用需求 ID 和场景 ID，避免“实现记忆模块”这类无法验收的描述。
