# 研发路线图

## Phase 1：事实与回放

事件 schema、身份、Ledger、投影、虚拟时钟和模拟平台。

## Phase 2：反应式消息处理

Mailbox、窗口、唤醒门、打断和 Outbox。

## Phase 3：最小角色与关系

角色定义版本、明确偏好、关系边界和行为/表达分离。

## Phase 4：记忆生命周期

候选、来源、纠正、作用域、多信号检索和维护。

## Phase 5：能力与承诺

工具注册、异步任务、确认、持久调度和主动履约。

## Phase 6：多平台与模型路由

第二平台接入、身份绑定、模型评估和故障路由。

## Phase 7：长期仿真与高级自主

长周期场景、主动建议、受限关系模型和可能的多 Agent 实验。

每个 Phase 的进入条件是前一阶段有可复现基线，而不是功能清单完成。
