# Nous × Heptalogos 架构

[项目宪纲](项目宪纲.md)是两个产品的最高需求权威。本仓库维护跨产品的目标、责任与后续开发方向。

Heptalogos 以 [MaiBot 源码](https://github.com/Mai-with-u/MaiBot)为基础，发展持续生活与行动的主体内核；[Nous](https://github.com/Heptalogos-Devs/Nous-Wave) 是独立安装的 Python + Native 长期认知服务，也是 Heptalogos 的认知权威。两者各自持有数据，通过正式接口与稳定逻辑主体身份协作。

从[宪纲定位](宪纲定位.md)了解领域归属，从[整体架构与模块合同](设计/整体架构与模块合同.md)了解产品边界、认知与行动的调用关系；[施工顺序](施工顺序.md)和[GOAL](GOAL.md)说明下一步。[索引](INDEX.md)列出文档入口，[研究](研究/README.md)保存原实现的调查材料。

当前 Heptalogos `main` 是尚未改造主体内核的 MaiBot Fork；Nous `main` 是 Python/Native 实现，模型角色注册与应用组装尚未完成。实际代码状态和开发入口分别见 [Heptalogos](https://github.com/Heptalogos-Devs/Heptalogos) 与 [Nous](https://github.com/Heptalogos-Devs/Nous-Wave)。
