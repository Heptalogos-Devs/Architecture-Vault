# Nous × Heptalogos 架构

[项目宪纲](项目宪纲.md)是两个产品的最高需求权威。本仓库维护跨产品的目标、领域责任与现行开发设计。

**[Heptalogos](https://github.com/Heptalogos-Devs/Heptalogos)** 以 [MaiBot 源码](https://github.com/Mai-with-u/MaiBot)为基础，发展具有世界时间、持续生活、注意和行动的主体内核。

**[Nous](https://github.com/Heptalogos-Devs/Nous)** 是可以独立安装和使用的 Python + Native 认知产品，提供通用记忆、NousQL、Wave 检索、Ego、Social、Motivation 及主动上下文。Heptalogos 通过正式接口使用 Nous 的认知能力。两者分别持有自身的世界行为与认知数据。

阅读 [整体架构与模块合同](设计/整体架构与模块合同.md)了解产品与数据归属，阅读 [Nous 原生认知与交互](设计/Nous原生认知与交互.md)了解正在采用的内部和公共接口设计。[施工顺序](施工顺序.md)说明接下来的开发顺序；[文档索引](INDEX.md)列出其他资料，[研究](研究/README.md)保留已有源码研究。

产品的当前实现、安装及开发进度以各自仓库为准。

当前优先完善 Nous 原生能力、简单操作流程与四类入口。SDK 随正式操作演进；独立发行和 A-Memorix 兼容适配在 Nous 完整稳定后推进。Heptalogos 后续在自身仓库完成主体内核与宿主接线。
