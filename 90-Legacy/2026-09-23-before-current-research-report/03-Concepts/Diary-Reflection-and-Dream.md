# 日记、反思与梦

## 定位

日记和梦属于离线主观认知，不是事实来源。它们用于压缩经历、提出问题、形成候选和探索联想，不能直接改写主体世界。

## 日记

日记输入可以包括：

- 当日重要事件；
- 情绪变化；
- 承诺和任务状态；
- 关系变化候选；
- 成功与失败的行动；
- 未解决问题。

日记输出：

- salient events；
- subjective interpretations；
- emotion summary；
- unresolved questions；
- memory candidates；
- procedural lessons；
- self-narrative candidates；
- 来源和置信度。

日记可以提议合并 Episode、保存经验或更新自我叙事，但不能直接完成这些提交。

## 反思

反思是从多次经历或工具反馈中形成较高层认识。它的价值主要在：

- 找出重复错误；
- 形成程序性经验；
- 发现目标或关系中的未解决张力；
- 提议新的评估场景；
- 改进未来策略。

反思属于主体解释，不能冒充用户事实或外部事实。

## 梦

梦定义为：

> 在离线、无外部副作用、低事实约束的沙箱中，对获准的记忆、情绪、目标和未解决张力进行随机化重组。

梦记录必须固定：

```text
epistemic_origin = dreamed
fact_authority = none
may_update_world_fact = false
may_update_relation_evidence = false
may_update_core_identity = false
may_call_write_tools = false
```

梦可以产生：

- 创意灵感；
- 隐喻和非事实叙事；
- 反思问题；
- 待审查的联想；
- 极轻、可衰减的情绪背景候选。

梦不能产生：

- 某人真实说过的话；
- 关系变化证据；
- 生活时间线事实；
- 工具执行结果；
- 用户偏好事实；
- 未经审查的人格变化。

## 运行边界

日记、反思和梦适合由 Python 离线 Worker 生成候选。TypeScript 在线内核负责：

- 选择可用素材和作用域；
- 提交任务；
- 保存结果及来源；
- 执行晋升审查；
- 决定候选是否影响记忆、策略或情绪。

## 进入主线的条件

这些机制只有在满足以下条件后进入核心产品：

- 事实污染率为零或达到明确门槛；
- 不产生未经批准的外部副作用；
- 消融实验显示对后续行为或创意任务有稳定增益；
- 成本和人格漂移可控；
- 用户可以关闭、检查和删除相关数据。

## 开放问题

- 日记周期和素材选择；
- 反思如何形成程序性记忆；
- 自我叙事候选的审查机制；
- 梦对情绪是否应有任何直接影响；
- 如何设计不鼓励事实污染的实验。
