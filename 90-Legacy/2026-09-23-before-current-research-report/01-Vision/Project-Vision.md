# Heptalogos 项目愿景

## 一句话定义

Heptalogos 是面向真实即时通信事件流的长期人工主体运行系统。

它研究的不是“如何让一句回复像真人”，而是：

> 如何让同一个人工主体在时间、关系、经历、任务、知识边界、多个会话和多个平台之间持续存在，并以可解释、可修正、受控的方式行动。

## 用户应感受到什么

- 它理解当前发生的完整事件，而不是只看到最后一句话；
- 它不必对每条消息立即回复，会等待、沉默、取消或延后；
- 它记得应该记住的经历，也能承认错误和接受纠正；
- 它对不同的人有差异，但不会随意编造关系或泄露私密内容；
- 它有自己的活动、任务、承诺和时间位置；
- 它知道自身知识边界，不把基础模型的潜在知识全部冒充为主体知识；
- 它使用工具时仍保持同一身份，并诚实表达成功、失败和不确定；
- 它可以主动，但主动行为有理由、有边界并可被关闭。

## 系统观点

传统模型接口解决：

```text
input → response
```

Heptalogos 解决：

```text
world events
→ facts
→ current situation
→ subject snapshot
→ cognition
→ behavior
→ action
→ consequence
→ new experience
```

模型提供推理和表达能力，但不能独自决定：

- 主体是谁；
- 主体经历过什么；
- 主体现在正在做什么；
- 主体与某人的关系；
- 主体知道或相信什么；
- 工具是否真实完成；
- 哪些长期状态应被修改。

这些由持久事实、状态、策略和统一认知提交共同约束。

## 核心组成

```text
Core Identity
+ Living State
+ Social Relations
+ Memory and Epistemic State
+ Tasks, Commitments and Time
+ Cognitive Kernel
+ Capabilities
+ Interaction Gateway
+ Trace and Replay
```

模块共同服务于一个主体，不是多个模块角色或多个自主人格。

## 研究目标

1. 证明事件流、消息窗口和行为/表达分离能改善 IM 时机。
2. 建立可回放的长期状态和统一主体提交机制。
3. 形成有来源、可纠正、带作用域的记忆和关系。
4. 将日程、承诺、生活时间线和自我陈述纳入持续约束。
5. 安全编排云模型、工具、工作流和受限子 Agent。
6. 用场景、虚拟时间、消融和影子运行验证真实增益。

## 当前边界

Heptalogos 是研究原型，不承诺生产 SLA、大规模多租户、完整人类心理模型或通用自主智能。详细边界见 [范围与非目标](Scope-and-Non-Goals.md)。

## 成功标准

成功不是模型在单轮对话中表现得更聪明，而是长期轨迹中：

- 行为时机更自然；
- 事实和承诺更可靠；
- 关系和人格更稳定；
- 错误可以被解释和修正；
- 工具和主动行为不越权；
- 更换模型或重启进程后主体仍保持连续性。
